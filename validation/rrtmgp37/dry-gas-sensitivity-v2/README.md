# Controlled native dry-gas sensitivity

This evidence package contains a four-call, one-column standalone replay. At the captured RRTMGP call for domain 1, i=24, j=55, step 2161 (source second 129600), the two counterfactual inputs replace only the 44 native `NATIVE_DRY_LAYER_MASS_KG_M2` entries with values transformed from the same-call RRTMG4 `COLDry` (LW) and `COLDRY` (SW) observer exports. Baseline inputs, actual captures, and the RRTMG4 exports are reused from the PR75 evidence at `../rrtmg4-same-call-attribution/`; they are pinned in `external-pins.json` instead of copied. The RRTMG4 exports come from PR75's diagnostic observer path with the three UDM radius options enabled; they do not represent default RRTMG4 operational-path output. Default-RA4 preservation is a separate PR76 result.

Run the portable verifier from this directory with Python 3:

```sh
python3 -B verify_package.py
```

It uses only the standard library. It checks the closed package file roster and hashes, the reused PR75 artifact pins, exact phase/header/section counts and shapes, the four-call receipt and outputs, binary64-exact dry-mass conversion for native layers, achieved gas-column agreement within one binary64 ULP, unchanged upper-extension gas columns, bitwise-held cloud/CU/precipitation/frozen/mask/radius result sections, and mandatory aggregate-flux/heating plus SW-direct identity to the captured REAL32 values. It also compares selected surface/TOA and heating results against the archived analysis. It prints recomputed descriptive deltas; it does not run the radiation solver.

The executed sensitivity changed gas dry column and therefore gas optical depth and the radiative solution. The measured input residual between native GP dry columns and the RRTMG4 observer columns is 0.1651868890% mean absolute relative and 0.2891570627% maximum over 44 native levels, computed as `(legacy - native GP) / native GP` (maximum at layer 19). A prior PR75 summary's 0.2883233554% maximum uses the legacy column as denominator and includes solver-level mean summaries over 57 LW and 45 SW levels; these figures have different denominators/extents and are not contradictory. The dry-mass counterfactual leaves the 13 LW and 1 SW upper-extension input levels unchanged, but upper-extension heating can still change through radiative coupling: maximum absolute deltas are 4.9968178619e-5 K day-1 for LW and 5.7099998805e-6 K day-1 for SW.

Selected counterfactual-minus-baseline changes are: LW surface all-sky/clear-sky downward flux +0.008409/+0.089157 W m-2, TOA all-sky/clear-sky upward flux -0.000196/-0.061283 W m-2, and layer-31 heating +2.6333e-4 K day-1 (maximum native-layer absolute change 7.5126e-4 at layer 6). SW surface all-sky/clear-sky downward flux -0.000213/-0.069177 W m-2, TOA all-sky/clear-sky upward flux -0.001441/+0.017383 W m-2, and layer-31 heating -1.3293e-5 K day-1 (maximum native-layer absolute change 2.1253e-4 at layer 44). These are standalone one-column sensitivity values, not forecast effects or error estimates.

The four standalone outputs are gzip-compressed deterministically under `outputs/`; their decompressed hashes and sizes match the original run receipt. The two changed inputs are included under `inputs/`. The actual same-call capture inputs/results and selected RRTMG4 observer exports remain available through the pinned PR75 paths. Build, source, runner, plan, execution authorization, postbuild identity and independent-review records are retained under `evidence/` and `source/`; some archived records contain their original absolute workspace paths and are provenance snapshots, not relocatable build instructions.

Scope is deliberately narrow. This is a controlled sensitivity for one captured column and one LW/SW call, not an accuracy comparison, domain-wide estimate, observational result, or production-default recommendation. It does not establish which dry-column convention is physically superior. For baseline standalone replay versus the same-call WRF capture, SW visible/NIR spectral partitions are not all identical after REAL32 serialization. NIRDIR differs by at most 2 REAL32 ULP and 7.8455e-6 W m-2; the other five exported VIS/NIR partition fields differ by at most 1 ULP. A source review found different accumulation precision/order consistent with this small partition mismatch, but did not run a per-band emulation proving it explains every bit. This is separate from the aggregate UP/DN/HR float32 identity checks and does not describe the dry-mass counterfactual partition deltas. The observer exports and their underlying runtime/build provenance are inherited from PR75; the package makes no new WRF forecast or REAL initialization.

The design-v2 provenance note is included as an erratum: its dependency/design bytes were amended after an earlier review to correct the frozen-table pin, and the earlier bytes were not recoverable. The included v3 design/dependency files are the corrected authoritative versions.
