# CF0 precipitation held-state audit: preparation

This package documents an optional sixth argument to the standalone test reference. It adds a single-column V8/V9 audit sidecar without changing production physics, cloud fraction, microphysics, Registry or vendor code. Existing calls with no sidecar retain their multi-column interface. A sidecar is restricted to one column.

**The eight audit solver calls are NOT_EXECUTED.** Four completed unmodified original calls are summarized in [baseline-summary.json](baseline-summary.json); they provide exact double outputs for the future four all-zero controls. Positive audit results are not yet present. The [summary](summary.json) stays a preparation ledger until actual execution and independent review. No solver, model, REAL or build was run while preparing this package. The current checked-in helper adds a validation-only guard requiring finite CF in [0,1] and exact zero for positive audit paths; see [the precise delta](forensic/current-test-helper-cf-guard.diff). It has not been locally compiled. The historical compiled v2 proposal remains unchanged and has a different source SHA; its selected captured inputs must satisfy this new precondition.

The historical [proposal status](forensic/proposal-status-v2.json) remains verbatim and describes its then-uncompiled state. The later [isolated build receipt](build/build-receipt.json) records one successful compile/link with zero solver calls. The [static review](review/static-review.json) requires a separately reviewed launcher: the offline gate alone does not establish coefficient directory, output ownership or resolved loader closure. Forensic helper copies are nonportable workspace snapshots. The checked-in Python parser and its 23 controls are portable standard-library checks; they do **not** execute or prove the compiled Fortran reader's error paths.

Before execution, the launcher must enforce an exclusive new output directory, exact short-relative argv, policy 1 and empty override, the pinned coefficient directory, cwd/environment, no LD_PRELOAD and actual resolved library hashes. It must consume one-use approval, durably record child PID/return code before comparison, run four zero controls first, stop on any failure and rehash all original artifacts before/after/finally. No original output may be overwritten.

Positive audit paths must exactly match the raw omitted rain or snow grid paths at CF zero, with native-only shape, zero padding, one species and occurrence exactly one. Snow requires explicit native source-radius capability and matching prepared radius; no background radius or tiny-mass filter is introduced. All 13 strictly positive snow layers are retained; six larger layers are a descriptive subset, not a cutoff. Extra precipitation is added **after cloud sampling** and before frozen optics/RTE. This studies the declared occurrence-one contribution, not an occurrence oracle or a physical-accuracy result.

`PREPARED_*` retains the baseline cloud-plus-accepted-precipitation solver optics. Original masks, gases, frozen optics, clear-sky fields and pre-delta direct diagnostics remain baseline quantities; ordinary all-sky total optics/flux/heating may change. SW emits a separate `AUDIT_DIRECT_PREDELTA` with extra raw precipitation extinction. Do not describe unchanged ordinary pre-delta diagnostics as the intervention's direct flux.

The selected original and patched executables link historical focused-v2 archives and 47 runtime libraries. Although the reference source matches the current source before this patch, this closure differs from the current private-scalar backend. Reusing it does not establish current forecast equivalence, domain-average response, occurrence validity or LUT clipping accuracy. No binaries, coefficients, NetCDF, large raw arrays, full logs or bytecode are retained here. Large originals and failed generations remain external path/SHA references in [index.json](index.json).

`python3 -I -S verify_artifacts.py` checks retained hashes and compact preparation contracts. It does not recompute external arrays or invoke forensic helpers. The provisional manifest will be extended only after actual reviewed intervention results; no result pin is fabricated now.
