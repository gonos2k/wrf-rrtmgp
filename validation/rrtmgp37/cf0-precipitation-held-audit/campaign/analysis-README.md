# CF0 rain/snow audit campaign: post-run results

This is a read-only analysis of the eight calls already recorded in `build/udm37-cf0-precip-campaign-v5/execution.json`; it launches no solver. The campaign receipt reports all eight calls successful, and postflight confirms the 281 immutable pins, generated outputs, and 47-library runtime closure remained unchanged.

The four present-but-zero sidecars reproduced the corresponding saved double-reference result files byte for byte. The positive sidecars passed the declared output contract: only the phase's explicitly mutable all-sky optics/flux/heating fields changed, while original protected sections remained exact. The precise result paths, sizes, hashes, unchanged section names, per-section changes, optics ranges, sums, and boundary-flux deltas are in `analysis.json`.

Positive cases use occurrence-one precipitation path proxies at held cloud-fraction-zero columns. For rain, the source captures contain 16 positive native layers and a raw path sum of 202.428637 g m⁻²; snow has 13 positive native layers and 5.622483 g m⁻². Added scaled extinction (`AUDIT_EXTRA_PRECIP_TAU`) sums over native layer-band elements to 1.068823 (rain LW), 3.019330 (rain SW), 1.235367 (snow LW), and 0.470762 (snow SW). These are simple sums across spectral bands and layers, not vertically integrated optical depth or a mass budget. The audit-added optical arrays are zero in the engine-only upper extension layers.

Against each saved double-reference result, the positive-case surface-down flux changes were +0.149682 W m⁻² (rain LW), +0.158826 (snow LW), −1.538515 (rain SW), and −0.041570 (snow SW). SW surface net-down changes were −1.252469 and −0.033988 W m⁻²; TOA up-flux changes were −1.946344 and +0.025166 W m⁻². LW surface-down is the reported GLW analogue; LW TOA up-flux is the OLR analogue. Maximum absolute heating changes within 39 native layers were 2.271922, 0.996969, 0.341847, and 0.001119 K day⁻¹ for rain LW, snow LW, rain SW, and snow SW respectively. Extension-layer maxima are separately recorded in the JSON.

These values measure a narrow, prescribed conditional-occurrence-one sensitivity. They do not establish the correct occurrence policy, independent optical truth, a domain-wide correction, forecast error, or accuracy. In particular, the positive sensitivity is not evidence that the current production model should use occurrence one for precipitation below cloud fraction zero.
