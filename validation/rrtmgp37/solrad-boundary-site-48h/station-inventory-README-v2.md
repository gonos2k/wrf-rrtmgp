# Matthew 48 h observational inventory (v2)

This read-only update corrects the station-availability interpretation in `inventory.json`; that v1 file remains unchanged. It inventories the validated RA4/RA37 paired 48 h run and official NOAA SOLRAD coverage. No new data were downloaded, no forecast was run, and no model-observation score was calculated in this step.

The paired forecast is 2016-10-06 00Z through 2016-10-08 00Z, with 49 hourly histories on a 90×99, 27 km Mercator grid. Its execution receipt is `build/udm37-matthew-dt60-paired-48h-v1/execution-receipt.json` (SHA-256 `e1df2908…d1bea`), status `PASS_BOTH_VALIDATED_DESCRIPTIVE`; the result is a coupled trajectory comparison, not an observational-accuracy test. Full hashes and configuration are in `inventory-v2.json`.

Of NOAA SOLRAD’s three geographically in-domain stations checked here, only Sterling (STE) has confirmed October 2016 coverage. The 2016 data-finder page identifies minute-average data, the station page distinguishes its current coordinates from the pre-2014 site, and the actual 2016 daily file headers give 38.97203 N, 77.48690 W, 85 m. The three already-staged files for October 6–8 each contain 1,440 minute records. The nearest model cell is (i=37,j=97), 9.01 km away; its terrain elevation is 101.0 m and it is land. The nearest outer-grid cell is 48.0 km from the station. NOAA reports SOLRAD one-minute averages from one-second samples after 2015-01-01.

Oak Ridge (ORT) and Tallahassee (TLH) are geographically inside the grid but are not 2016 observation sites: NOAA’s 2016 summary report lists operation end dates of 2007-06-08 and 2002-10-30, respectively. A single request for each 2016 daily file returned HTTP 403. BON/BND, PSU, and GWN SURFRAD sites are outside the model domain (nearest distances 105.66, 147.21, and 220.05 km) and are excluded from comparison; boundary-cell substitution is not appropriate.

SOLRAD provides shortwave/global, direct, and diffuse measurements, not the longwave comparison fields. Any later STE comparison must validate minute timestamps/QC/missing rows and solar direct-field convention before use. NOAA’s file README says post-2015 samples are one-minute averages and describes QC flags (0 good; positive flags indicate QC failures; missing values are `-9999.9` with QC=1). It also notes small nighttime negative global/diffuse readings can be physical instrument offset, so these must not be clamped automatically.

Official references: [SOLRAD station/frequency page](https://gml.noaa.gov/grad/solrad/), [2016 GML summary report](https://gml.noaa.gov/publications/summary_reports/summary_report_28.pdf), [STE 2016 dataset page](https://gml.noaa.gov/data/dataset.php?item=ste-solrad-2016), and [daily-file format/QC README](https://gml.noaa.gov/aftp/data/radiation/solrad/README_SOLRAD.txt).
