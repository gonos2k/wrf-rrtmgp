# Independent SI Planck/source comparison — design v2

This is an additive correction to the design in the parent directory; v1 remains unchanged. V2 pins the actual production source tree at `build/udm37-bon-common-band-source-pr-work/WRF/external/rte_rrtmgp`. A sibling `external/rte-rrtmgp` tree has different source hashes and must not be substituted.

The pinned LW coefficient file directly contains the raw per-band `totplnk` table (16 bands × 196 Planck-temperature rows), so the raw band values for a selected column can be reconstructed without a new compiled observer. The production frontend sets `totplnk_delta=(temp_ref_max-temp_ref_min)/(nPlanckTemp-1)` from `temp_ref` endpoints 160 K and 355 K; the table index coordinate is 0–195. Use the exact production `interpolate1D` algorithm, including its index clamping, on the captured `TLAY`, `TLEV`, and `TSFC` fields. The kernel applies the same band Planck value to g-points only after computing `pfrac`.

The relevant production kernel computes `SOURCE_LAYER = pfrac * raw_band_Planck`. Consequently, summing a retained source by band and dividing by the reconstructed raw band Planck gives an inferred fraction sum and can check consistency of that already-mapped output. It is **not** independent validation of the `pfrac` interpolation: the source being measured already contains that interpolation. Independent validation of `pfrac` still needs either a captured pre-mapping fraction array or a separate reconstruction from the pinned fraction table with the exact flavor, interpolation weights, and state indices. No such array is in the retained GP sidecar. Interior interface source uses the geometric mean of adjacent layer fractions, so neither adjacent layer's fraction is a valid substitute.

The future SI reference uses exact constants from [NIST SP 330, Section 2](https://www.nist.gov/pml/special-publication-330/sp-330-section-2). With wavenumber `sigma` in m⁻¹, transform Planck spectral radiance to `B_sigma(T)=2hc² sigma³ / expm1(hc sigma/(kT))`, then integrate between 100 times the band edges expressed in cm⁻¹. The SI variable transformation is derived from Planck's spectral-radiance law described in [NIST Technical Note 910-8](https://nvlpubs.nist.gov/nistpubs/Legacy/TN/nbstechnicalnote910-8.pdf); NIST lists the wavenumber SI unit as reciprocal metre in its [Guide to the SI](https://www.nist.gov/pml/special-publication-811/nist-guide-si-chapter-4-two-classes-si-units-and-si-prefixes). Use float64 and report quadrature convergence. No integral has been performed in this preparation.

Only physical bands 3–13 are common, spanning 500–2250 cm⁻¹. Do not compare bands 1–2 or 14–16, and do not pair or average g-points across the 140- and 128-point schemes. Keep native raw Planck, `DELWAVE`, legacy `WTDIFF=0.5`, and `FLUXFAC=pi*2e4` separately visible. The inspected legacy source calls its Planck values integrated by band and says units are generally cgs, but neither its exported field nor the pinned GP table has a units attribute that settles raw ordinate scaling by itself. Derive the legacy scale from table construction and constants; do not introduce a fitted factor. Legacy surface raw Planck already includes emissivity; GP source does not, so apply emissivity exactly once only for emitted surface quantities.

The known band-12 upper-layer zero-fraction case remains an explicit example of why raw Planck and fraction mapping must be reported separately. Zero fractions are preserved as supplied; never renormalize them. This design sets no tolerance and makes no accuracy or engine-preference claim.

## Legacy scale resolved from the pinned source

The production legacy source documents `radcn1=1.191042722e-12 W cm² sr⁻¹`; with wavenumber in cm⁻¹, `radcn1 * wavenumber³` is spectral radiance per cm⁻¹. Integrating across `DELWAVE` therefore gives W cm⁻² sr⁻¹. The raw native band radiance candidate is `RTE_PLANCK_*_NATIVE * DELWAVE * 1e4` in W m⁻² sr⁻¹. This matches the transport conversion path: `WTDIFF=0.5` times `FLUXFAC=pi*2e4` is `pi*1e4`, converting that native integrated radiance to hemispheric flux. The legacy constants are rounded, whereas the planned SI reference uses exact NIST constants; preserve any small difference in the result rather than fitting it away.

This source-backed legacy unit derivation does not create a GP units attribute. The pinned GP `totplnk` table remains directly reconstructible by the production interpolation and can be compared numerically with the SI integral, while its file omits explicit units metadata. Most importantly, the raw GP band Planck values are now recoverable from the pinned NetCDF and production lookup; the missing field is the independently interpolated `pfrac`, which is required to validate fraction interpolation rather than merely infer a fraction sum from already-mapped sources.
