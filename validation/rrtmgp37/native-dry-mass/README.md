# UDM27 native dry-mass execution evidence

The tested change supplies native WRF dry-layer mass to production option 37 water paths. The legacy hydrostatic `DP_HPA*100/g` includes moisture loading. Mixing ratios per kg dry air require `-DNW*(C1H*MUT+C2H)/g`; production 37 no longer uses the pressure approximation for hydrometeors. Direct historical builder callers may still omit the optional mass array. Option 4 arithmetic is preserved.

The source state is the listed uncommitted PR15 files on parent `9d22bca5807de135d72719404b04954908323d4e`, recorded in `provenance.json`. That parent SHA alone does not identify the modified binary. The build was an incremental GNU serial `em_scm_xy` rebuild; the standalone CMake directory was fresh. Remote fresh-checkout CI is separate evidence.

At first call, the dry column mass is approximately 8080.05349 kg/m². Pressure-mass column excess is 9.861215 kg/m² for control and 9.871170 kg/m² for mixed. It closes against native mass times `1+QV+QC+QR+QI+QS+QG+QH` within the separately stated REAL32 interface-subtraction bound. This identifies the denominator mismatch; it does not explain all 4/37 flux differences.

`control.json` and `mixed.json` contain source, executable, history, raw/input hashes and measured errors. Raw files have no timestamp; the initial timestamp is bound by exact q and coordinate fingerprints to the selected history record and wrfinput. `scm-summary.json` retains regression and support-gate receipts; `prebuild-binaries.json` identifies the frozen comparison executables. `ctest.log` and `provenance.json` preserve the test inventory, source and build-log hashes. Large binaries, NetCDF histories and compile logs remain in the local build directory and are regenerated by CI.

The unchanged graupel omission, positive-hail refusal and CF=0 condensate policy still limit the supported state space. This is not new MPI/OpenMP, restart, nest, completed 24-hour option-37 forecast or observational accuracy evidence. Gas column and heating pressure denominators were not changed. Native UDM ice-size metric equivalence to the RRTMGP LUT remains a separate investigation. See [the input contract](../../../WRF/doc/rrtmgp/NATIVE_DRY_MASS.md).

## Same-state path-only counterfactual

`counterfactual.json` compares captured native paths with clipped raw q times `DP_HPA*100/g`, changing only LWP/IWP/RWP/SWP. CF, pressure, gas, temperature, sizes, constants, surface, seeds and extension-zero paths are held fixed. The 32 paired seeds include the operational captured seed. Mixed SW surface-down legacy-minus-native is −0.001770 W/m² for that seed and −0.002273 W/m² for the paired mean (SD 0.001781, maximum absolute sample difference 0.006912). Mixed LW surface-down paired mean is +1.4763e−5 W/m². Clear control flux/heating differences are zero; all output sections are bitwise identical to explicit-zero-path control. This is one first-call column per case, not a forecast attribution or an accuracy verdict.

The published runner bytes match the recorded executed script hash; its original local path is retained in the 32-seed receipt. To repeat after generating paired SCM captures and a reference executable, run from the checkout with an unused output directory:

```bash
python3 validation/rrtmgp37/native-dry-mass/run_counterfactual.py \
  --repo-root "$PWD" --case-root "$PWD/build/udm-native-dry-mass-pr15" \
  --reference-executable "$PWD/build/udm-native-dry-mass-pr15/standalone/reference_column" \
  --data-directory "$PWD/WRF/run" \
  --output-directory "$PWD/build/new-path-counterfactual" --seeds 32
```

Set the runtime NetCDF library path as for other reference tests. The runner locates the checkout from its published location; explicit CLI roots were smoke-tested with two seeds.
