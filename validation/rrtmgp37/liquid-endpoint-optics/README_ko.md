# 동일 상태의 LUT 끝값·독립 끝값·독립 실제 반경 판정

PR #182의 범위 밖 성분 제거와 5분 물수지 귀속은 완료로 유지한다. 이 자료는
성분을 제거하지 않고, 같은 액체 물경로의 광학 정의와 반경 제한 효과를 분리한다.
기준 main은 `66f3f7aff699638a644491cf6df674905db706a3`, tree는
`08f24b0500b147526d9816c8c9477e38f919c68e`이다.

**결정: 현 끝값 제한을 연구용 수치 보호로 유지한다. 범위 밖 과학적 적용은
보류한다. 이번 독립 계수를 생산 대체로 채택하지 않는다.** 생산 WRF·UDM·RTE,
기본값, 반경, 계수 파일은 변경하지 않았다. 새 policy도 없다.

## 사전 규약과 실제 수행

`plan.json`을 독립 계산 전에 작성했다. 실행 결과의 `plan_sha256`은 그 원본
bytes를 묶는다. 격자 세분화 기준은 계수 네 모멘트의 상대차 1%
(분모 하한 1e-8 m²/g), g 절대차 0.002이다. 실제 수송 결과의 세분화 기준은
플럭스 0.02 W/m², 가열률 0.02 K/day이다. **이는 수치 수렴 기준이며
관측 정확도나 물리 허용기준이 아니다.** 사용 목적과 독립 불확실도에 근거한
물리 허용기준이 아직 없으므로, 작은 차이로 과학적 승인을 내리지 않도록
사전에 결정했다. 결과를 보고 기준을 완화하지 않았다.

같은 #182의 두 실제 WRF capture를 사용했다.

| 실제 source | 선택 native 층 | 실제 Gamma8 반경, μm |
|---|---|---|
| 54,300초 야간 LW | 1, 23 | 22.410273, 21.516813 |
| 65,100초 주간 LW/SW | 1, 2, 23 | 27.660246, 22.109638, 22.125196 |

A는 원 LUT의 21.5 μm 끝값, B는 독립 광학의 21.5 μm,
C는 **B와 같은 독립 정의**의 위 실제 반경이다. B는 새로운 host number 상태가
아니라 동일 물경로에 주는 광학 대조다. 입력 q·number·CF·기체·rain·seed·
열용량은 그대로다. 낮은 반경 사례나 24시간 전체의 최대 반경 55 μm까지
이번에 검증한 것으로 확대하지 않는다.

독립 계산은 기존 `miepython 3.2.0` 구형 입자 엔진과 보존된 Segelstein
25°C 자료를 사용했다. number-Gamma shape8, 유효분산0.1, 물 밀도1000 kg/m³,
n 선형/k 로그 보간을 고정했다. 원 밴드의 파수 구간에서 SW Planck5780 K,
LW Planck298.15 K 가중을 사용했다. 전 밴드(16 LW·14 SW)를 **선택한 반경에서만**
계산했다. 원 LUT가 같은 자료·PSD·온도·가중으로 생성됐다는 인증은 아니다.
실제 층 온도 의존성도 이번 범위가 아니다. 원 표의 출처·라이선스 설명은
`saved/water/Segelstein.yml.gz`에 보존했다.

면적가중 Gamma 적분으로 ext, sca, abs, sca×g [m²/g]를 구했다.
반경 적분은 x=λr의 0–80 범위 Simpson, 파수는 Gauss–Legendre 적분이다.
초기 512/48, 1024/96점에서 시작해 필요한 조합만 2048/192, 4096/384점으로
확장했다. 엔진의 기존 참조값 회귀도 실행 전에 검사했다.

## 광학 대입 경계

`build_diagnostic.py`는 생산 어댑터를 **별도 이름의 진단 모듈**로 복사해 빌드한다.
일반 WRF 실행파일이나 라이브러리를 덮어쓰지 않는다. 변경은 모듈 이름·USE와
네 개의 액체 광학 호출 직후 hook뿐이며 저장 검증기가 정확한 차분을 확인한다.

- Native 액체와 uniform CF0 액체에 같은 raw 모멘트 정의를 적용한다.
- 선택 층의 액체만 대입하고, 선택하지 않은 층·precip·clear·mask·열용량은 보존한다.
- LW는 현재 어댑터와 같이 **흡수**를 사용한다. 독립 소광·산란 모멘트는 따로 저장한다.
- SW는 기존 precipitation 결합 전, 기존 **한 번의** delta scaling 전에 대입한다.
  raw 직달광 경로도 같은 소광을 소비한다. 전체 광학량을 다시 scaling하지 않는다.

이 상한 사례의 선택 층은 모두 CF>0이며 uniform 액체를 새로 만들지 않았다.
기존 uniform/rain 결과가 변하지 않음도 검사한다. 하한 CF0 사례의 과학적
승인이 추가됐다는 뜻은 아니다.

A의 모든 어댑터 result 배열의 형상·값은 실제 WRF capture와 정확히 같다.
WRF 호출자가 나중에 기록하는 `WRF_*` annotation은 이 standalone caller의
출력 대상이 아니므로 비교에서 구분했다. 실제 온위 source나 장기 예보를
이번 standalone 실행에서 새로 검증했다고 주장하지 않는다.

## 결과: 정의 차이와 반경 제한 차이는 별개다

아래는 native 경계 UP/DN 중 최대 절대 플럭스 차이와 native 층 가열률의
최대 절대차다. 가열률은 REAL64 K/s를 K/day로 환산했다. 서로 다른 위치의
최대값을 더하거나 빼서 차이를 재구성하지 않는다.

| 상태 | 비교 | 플럭스 W/m² | 가열률 K/day |
|---|---|---:|---:|
| 야간 LW | B−A: 광학 정의 | 0.048108 | 0.038319 |
| 야간 LW | C−B: 독립 정의 안의 반경 제한 | 0.031325 | 0.043215 |
| 야간 LW | C−A: 총 차이 | 0.050339 | 0.059578 |
| 주간 LW | B−A | 0.098004 | 0.076076 |
| 주간 LW | C−B | 0.161337 | 0.122747 |
| 주간 LW | C−A | 0.259341 | 0.198823 |
| 주간 SW | B−A | 0.005632 | 0.004414 |
| 주간 SW | C−B | 0.097236 | 0.003811 |
| 주간 SW | C−A | 0.097299 | 0.000871 |

같은 층·경계·밴드에서 signed B−A, C−B, C−A를 저장하고 항등식을 검사한다.
주간 SW 가열률에서는 정의 차이와 반경 효과가 상쇄된다. 총 차이가 작다는
이유로 두 효과를 각각 무시할 수 없다. `result.json`에는 raw τext, τsca,
τabs, τsca×g의 층·밴드 교차차이와 위치 대응도 있다. LW 확장 TOA를 native
상단으로 바꾸어 사용하지 않았다.

이 값들은 **명시한 독립 광학 정의 안의 고정 상태 민감도**다. 관측 오차,
24시간 예보 편향, 일반적인 clipping 오차 상한이 아니다. #182의 성분 제거
31 K/day를 반경 제한 편향이라고 해석하지 않는다.

## 수치 수렴의 한계도 보존한다

152개 반경·밴드 조합 중 150개가 계수 수렴 기준을 충족했다.
143개는 1024/96, 5개는 2048/192, 4개는 4096/384 격자가 최종 격자다.
마지막 4개 중 아래 2개는 **수렴 실패**로 보존한다.

| 조합 | 최종 흡수계수 m²/g | 마지막 흡수 상대차 |
|---|---:|---:|
| SW11, 22.125196 μm | 1.13131e-7 | 2.9378% |
| SW12, 끝값21.5 μm | 7.79446e-8 | 2.2462% |

나머지 소광·산란 등의 수렴으로 이 흡수 실패를 덮지 않았다.
각 조합의 마지막 두 격자 계수를 실제 RTE로 각각 소비해 확인한 최대 차이는
플럭스 **0.000653 W/m²**, 가열률 **0.000596 K/day** 이하였다. 따라서 이번
수송 진단의 사전 수렴 screen은 통과했지만, **전 계수 수렴 PASS는 아니다.**
두 가지 판정을 결과 파일과 검증기에서 분리한다.

## 처리 방침과 작업 종료

이번 A/B/C 질문은 종료한다. 현재 끝값 처리는 명시적인 연구용 수치 보호로
유지하고, 범위 밖 과학적 적용을 보류한다. 새 독립 계수를 즉시 생산에
대입하거나 LUT 상한만 늘리지 않는다. 실제 PSD·온도·분광 가중의 독립 근거와
사용 목적의 허용기준이 확보되면 그 범위에 한해 대체/확장을 별도 판단한다.

공통 PBL source·전체 host 물/에너지·기존 RFMIP/LBLRTM FAIL은 그대로다.
기존 일곱 종료 조건을 추가·변경하거나 연구 통합 완료를 과학 승인으로
승격하지 않았다. 동일 표본 계수나 5분 수지를 다시 추적할 이유도 없다.

## 실행 identity와 재생

새 WRF 실행·24시간 실행·standalone UDM·LBLRTM은 **0회**다.
독립 Mie 캠페인은152개 반경·밴드 조합, 총317개 quadrature 평가다.
적격 RTE 진단은 **15회**(3개 phase/capture × A·B·C·B/C 수렴 대조)다.
처음 A 실행 1회가 정상 종료한 뒤 verifier가 WRF-only annotation을 잘못
요구해 중단됐고, 그 기록도 보존했다. 실제 RTE 프로세스 총수는16회다.
Fortran 객체 컴파일6회·링크2회 중 첫 빌드는 실행하지 않았고, trace 이름만
구분한 두 번째 빌드를 모든 진단에 사용했다. 독립 기상 사례 수가 아니다.

`identity.json`은 생산 소스, 계수, 기존 라이브러리, 진단 실행파일, 엔진
소스 해시를 연결한다. `prior-evidence.json`은 #182 capture·입력과 원 LUT
추출 자료를 복사하지 않고 해시로 재사용한다. `saved/`에는 새 계수·격자별
결과·실행 장부·진단 소스·입출력과 초기 실패를 보존했다.

```sh
python3 -I -S validation/rrtmgp37/liquid-endpoint-optics/verify_saved.py
python3 -I -S validation/rrtmgp37/liquid-endpoint-optics/test_saved.py
python3 validation/rrtmgp37/acceptance/test_verify.py
```

위 명령은 보존 근거의 재생이며 모델/Mie를 새로 실행하지 않는다.
의미 반례는 B의 실제 반경 오대입, 중복 SW delta scaling, 비선택 층 변경,
흡수 수렴 실패의 PASS 승격을 거부하고, signed 차이와 최대값 차이를 구분한다.
새 계산을 재현할 때는 기존 의존성과 #182 입력 경로를 준비하고
`run_mie.py` → `build_diagnostic.py udm37-endpoint-column-v2` → `run_columns.py`
순서로 수행한다. 이미 있는 캠페인 디렉터리를 덮어쓰지 않는다.
