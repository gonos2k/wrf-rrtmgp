# Matthew case: preserved run evidence and scoped fatal diagnosis

This bundle records a 48-hour RA4 run, two RA37 attempts that stopped near the first 40 minutes, and the read-only postflight correction for RA4/REAL. It contains copied text receipts and logs only; NetCDF outputs and executables are referenced by SHA-256 and were not copied. Source run directories and receipts remain unchanged. See `forensic-summary.json` for machine-readable paths, pins, counts, and outcomes; `bundle-manifest.json` hashes the bundled files.

The original REAL receipt is `FAIL_PRESERVED`, even though `real.exe` returned zero. Its first validator used the wrong expected first time. The separate corrected postflight and combined review pass. The original files were not rewritten.

The original paired RA4 run completed all 48 hours: 49 history timestamps from 2016-10-06 00:00 through 2016-10-08 00:00 and four restart outputs. The original v1 validator nevertheless failed on an unsupported `RTHRATEN = LW + SW` equality test (7,258,112 mismatches; maximum absolute residual 6.608606781810522e-7) and on requiring history-style `MU`, `PH`, `U`, `V`, and `W` names in restart files. A separately pinned v2 validator checks the restart time-level variables and reports heating residuals diagnostically; it passes. The original pair execution receipt remains `FAIL_PRESERVED`, because RA37 had not run in that invocation.

The first RA37 continuation used OMP=2 and stopped at model time 00:40 with return code 1. Rank 0 recorded `application called MPI_Abort(MPI_COMM_WORLD, 1)`, but no WRF `FATAL CALLED` detail appeared. The preserved continuation receipt also records a post-processing scanner error: it expected success text on a failed-run error log, and the scanner did not match mixed-case `MPI_Abort`. The model return code remains recorded; no full postflight ran.

A separate, root-authorized one-hour RA37 diagnostic used OMP=1 and the same initial input, executable, coefficients, frozen table, and physics settings. It also stopped at 00:40 with return code 1. This time the rank-0 error log contains the explicit cause: a positive LW graupel path at batch `j=30`, `i=33–45`, column 10, layer 38 has temperature 179.996 K, below the table's 180 K lower bound. The path is 0.0006054224 g m-2 and the lookup uses 20000 m-1. Extrapolation is forbidden, so WRF stopped. This establishes a concrete table-coverage failure for this sampled state; it does not establish optical-flux accuracy or justify a new threshold, clipping policy, or table extension. The one-hour namelist was set to end at 2016-10-06 01:00; the model stopped earlier. No RA37 48-hour forecast or paired 48-hour difference statistics exist.

No forecast was rerun while curating this bundle. No coefficient table, production code, threshold, or model input was changed. The only diagnostic namelist changes from the staged 48-hour case were `run_hours=1`, `end_day=06`, and `end_hour=01`; OMP was set to one thread for the diagnostic invocation.
