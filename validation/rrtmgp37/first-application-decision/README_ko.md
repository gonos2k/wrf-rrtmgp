# 첫 적용 후보의 대상량·독립 기준과 수용판정

기준 main은 PR #183의 `0ae35fafb5196349cf97b4f6d64b432a86cc5fad`, tree는
`b8ca415354d225ad4dc6d28d8466d5b1f94e9a55`다. A/B/C·24시간·5분 PBL 귀속은
완료 근거로 유지한다. 생산 코드·계수·정책·원래 일곱 종료 조건은 변경하지 않았다.
새 WRF·UDM·RTE·Mie·LBLRTM 실행과 새로운 최상위 gate/acceptance 시험은 **0개**다.

**현재 판정은 액체 광학 근사의 첫 적용과 범위 밖 과학적 적용
보류다.** 정의가 명확한 고정 상태 민감도 연구에는 기존 결과를 사용할 수 있다.
두 미수렴 SW 흡수계수는 보존하고 이번에는 추가 계산하지 않는다. 그 두 값을
수렴시켜도 현재의 독립 기준·사용 목적 오차 예산 공백이 해소되지 않기 때문이다.
이 결정은 새로운 승인이나 생산 광학 대체가 아니다.

## 선택한 후보와 사용 목적의 상태

사용 목적과 허용오차에 대한 질문을 사용자에게 제시했다. 현재 기록에는 답변이
없으므로 **이번 판정의 첫 대상은 고정 상태 복사 진단**으로 정했다. 이는 사용자가
승인한 최종 요구사항이 아니다. `decision.json`에 그 상태를 구분한다.
실제 지역예보나24시간 정확도 판정에 이 범위를 전용하지 않는다.

- 산출물: 지표와 WRF native 상단의 LW/SW 상향·하향·순하향 플럭스[W/m²],
  native59층의 온도 등가 가열률[K/day]. 야간 SW는 이번에 평가하지 않았다.
- 상태: source54,300초 야간 LW와65,100초 주간 LW/SW의 보존된 실제 WRF
  기주. number1/population2/capacity1/liquid-size1, 원래 CF·mask·seed를 고정한다.
- 입자: Gamma8·Segelstein25°C·명시한 Planck 밴드 가중의 조건부 독립 광학.
  host 온도는 별개이며 선택 층에서 약289.24–293.08K다. 온도 의존성을 검증한
  것으로 읽지 않는다.
- 범위: 실제 선택한 다섯 반경 값(21.516813,22.109638,22.125196,22.410273,
  27.660246μm)에 대한 진단이다. 그 사이의 연속 범위,55μm,하한 이탈,혼합상,
  다른 CF/seed 분포까지 승인한 것이 아니다.

이산 상태별 q·eta·rho·CF·경로·온도는 `observables.json`에 연결했다.
새 대기 상태를 만들거나 number·CF를 보정하지 않았다. 여기서 경로는 원래
복사 입력 LWP이며, 격자평균 노출량으로 다시 해석하거나 CF로 다시 나누지 않는다.

첫 과학적 주장은 **고정된 기체·수송·CF·seed·열용량 아래의 액체 광학 근사가
해당 플럭스·가열률에 미치는 오차의 수용성**으로 한정한다. 전체 대기의 절대
정확도 승인이 아니다. 이 성분 판정에는 같은 수송 모델을 사용하는 적격 독립
액체 광학 기준을 사용할 수 있다. 공통 PBL이나 기존 RFMIP/LBL의 미완료를
새로운 직렬 선행조건으로 붙이지 않는다.

## 실제 판정 대상에서 읽은 결과

순하향은 DN−UP이다. 각 값은 같은 위치에서 계산한 signed 차이다.

| 상태/경계 | B−A 정의 차이 W/m² | C−B 반경 차이 W/m² | C−B의 마지막 두 격자 변화 W/m² |
|---|---:|---:|---:|
| 야간 LW 지표 | +0.00011168 | +0.00195970 | 4.29e-7 |
| 야간 LW native 상단 | −0.00126945 | −0.00006069 | 1.16e-7 |
| 주간 LW 지표 | −0.00484534 | +0.00729632 | 5.35e-7 |
| 주간 LW native 상단 | −0.00262681 | −0.00463396 | 2.53e-7 |
| 주간 SW 지표 | +0.00005197 | +0.08070606 | 4.16e-6 |
| 주간 SW native 상단 | −0.00344749 | +0.08258918 | 3.35e-4 |

이는 이전의 “모든 native 경계 UP/DN 중 최대값”과 다른 대상량이다.
확장층 TOA를 native 상단으로 쓰지 않았다. 상향·하향 각각의18개 경계 지표와
같은 위치의 A/B/C 값,177개 native 층 가열률을 파일에 보존했다.
층별 C−B 최대값은 PR #183의 야간 LW0.043215,주간 LW0.122747,
주간 SW0.003811K/day와 같은 기존 결과다. 새 solver 비교가 아니다.

각 대상량에서 `(C_f−B_f)−(C_c−B_c)`와
`|C_f−C_c|+|B_f−B_c|`도 같은 위치에서 구했다. 두 번째는 **두 격자 수준
사이 변화의 상계**이며 참적분 오차 상계가 아니다. 표의 작은 값이나 다른 층의
최대값을 실제 정확도·허용량으로 바꾸지 않는다. 가열률은 저장 REAL64 K/s를
86400배 했으며 WRF의 섭동 온위 T나 RTHRATEN과 혼용하지 않는다.

## 독립 기준을 선택하기 위한 실제 근거 확인

원 NetCDF 두 파일의 attributes·단위·2.5–21.5μm 범위를 직접 판독했다.
`inspected-LUT-metadata.json`에 파일 해시와 판독값을 저장했다. 생성 PSD·굴절률·
온도·밴드 가중은 metadata에서 확보되지 않았다. [고정 공식 README](https://raw.githubusercontent.com/earth-system-radiation/rrtmgp-data/ea788bb39876948fa8d2c235665ccff19b4686b5/README.md)도 cloud optics를 예시 구현으로 설명한다.
이것은 파일 계보의 확인이며 생성 정의의 완전한 인증이 아니다.

독립 후보는 **같은 상태를 보존하는 정의 일치 분광 액체 광학 기준**으로 정했다.
조건부 구형 입자 모델의 정확도는 적격 이론 기준으로 검증할 수 있으며, 관측을
모든 조건부 검증의 필수 요건으로 만들지는 않는다. 다만 실제 대기 적용에는
PSD·발생영역·입력 대표성의 별도 독립 근거가 필요하다.

| 현재 자료/후보 | 이 첫 판정에서의 역할과 제한 |
|---|---|
| PR #183 B/C | 생산 LUT를 입력하지 않은 명시적 광학 민감도 기준. 같은 RTE·가스·CF·seed를 공유하므로 전체 대기의 절대 정확도 reference는 아니다. |
| Feng et al.(2025)의 공개 방법 | 정의를 맞춘 PSD/밴드 적분 대조의 후보. 정의·불확실도 qualification이 아직 없다. |
| 원 LUT metadata·publisher bytes | 파일 정체성과 인터페이스를 인증한다. 빠진 생성 규약이나 물리 오차를 인증하지 않는다. |
| ARM 지표 복사 관측 | 실제 시공간·기기 교정·입력 상태를 맞추고 불확실성을 연결할 때 지표 평가에 사용할 수 있다. 현재 제조 기주의 대응 관측은 없다. |
| 기존 RFMIP/LBL | 각각의 원래 기준에서 FAIL을 유지한다. 액체 광학 비교로 대체하지 않는다. |

[Feng et al.(2025), §2.1–2.2](https://doi.org/10.1029/2024MS004478)는 명시한 PSD와
분광 평균 규약을 사용한다. 논문의 액체 LW 기준 source 온도와 SW 평균 방식은
PR #183의 규약과 다르다. 또한 [companion code의 고정 spec_util.py](https://github.com/GRIPS-code/cloud_rad_scheme/blob/fe1faba475479c873c88bc98755bcb8c5bb911b1/cloud_rad_scheme/spec_util.py)는 MiePython을 사용한다.
따라서 그 패키지를 그대로 실행해도 독립 Mie 커널 검증이나 원 LUT 인증이 되지
않는다. 공유 코드는 독립 커널 근거 두 개로 중복 집계하지 않는다는 뜻이며,
새 Mie 커널을 반드시 만들어야 한다거나 성분 기준으로 사용할 수 없다는 뜻은 아니다. 코드와 논문의 정확한 release 일치도 이번에 인증하지 않았다.
이 후보는 규약을 맞춘 성분별 교차검증에 사용할 수 있으며, 현재 승인된 대체
reference 경로로 기록하지 않는다.

[ARM SIRS handbook §5.1.2](https://www.arm.gov/publications/tech_reports/handbooks/sirs_handbook.pdf)는 측정식과 기기별 기여를 통해 불확실성을 평가한다.
이는 지표 관측 기준을 정하는 근거다. 일반적인 기기 목표 정확도를 모델의
허용오차로 채택하거나 층 가열률 불확실성으로 옮기지는 않는다.
`primary-sources.json`에 실제 내려받은 원 자료의 URL·해시와 고정 코드의 위치,
직접 확인한 사실 및 그로부터의 판단을 구분했다. 이 자료들의 solver는 실행하지 않았다.

## 오차 예산과 수용/보류 규칙

현재 `decision.json`의 epsilon·U_num·U_ref·U_repr는 모두 **null(미확정)**이다.
0이나 임의의 작은 수가 아니다. PR #183의0.02W/m²·0.02K/day는 수치 screen으로
유지하며 물리 epsilon으로 재사용하지 않는다.

| 항 | 필요한 근거 | 현재 판정 |
|---|---|---|
| D: 액체 광학 후보−적격 성분 기준 | 같은 물리량·경계·상태를 갖는 비교 | 미확정. A/B/C 차이는 D를 대체하지 않음 |
| U_num | 대상량에서 정당화한 참오차 한계/불확실도 | 마지막 두 수준 변화만 보유. 참오차 한계 미확정 |
| U_ref | 기준의 독립성·자료·방법·교정 및 적용 범위 | 적격 dossier 미확보 |
| U_repr | 목적에 필요한 PSD·온도·발생영역·표본 대표성 | 실제 대기 정확도에 대해서 미확정. 고정 가정에서 제외한 항은 claim 범위에도 포함하지 않음 |
| epsilon | 사용 목적에 근거한 허용량과 지정 권한 | 사용자 목적/오차 예산 미확정 |

모든 항이 같은 정의의 정당화된 상계로 확보됐다면
`|D|+U_num+U_ref+U_repr <= epsilon` 같은 보수적 규칙을 사용할 수 있다.
이는 현재 PASS 검사가 아니다. 성분 claim 밖의 기체·수송 오차를 0으로
승인하는 것도 아니다. 그 항들은 이번 수용 주장의 대상에서 분리했다. 상관·중복 항을 먼저 구분하며, 독립성 근거 없이
제곱합을 쓰지 않는다. 마지막 세분화 차이나 다른 논문의 보고 오차를 참오차 한계로
재명명하지 않는다. 결과보다 조금 큰 epsilon을 정해 통과시키지도 않는다.

현재 첫 후보의 **수용은 보류**한다. 부족한 다음 증거는 하나의
**정의 일치 액체 광학 기준·불확실도·사용 목적 오차 배분 dossier**다. 필요한 필드는
`decision.json/next_decision_evidence`에 고정했다. 원 PHY-SIZE 조건과 다른
검증 경로를 쓸 경우 그 대안의 명시적 승인을 먼저 기록해야 한다.
원 조건을 이번 문서만으로 교체한 것은 아니다.

두 SW 흡수계수의 전용 보강은 그 dossier가 해당 정확도를 요구하거나 생산 채택을
검토할 때 수행한다. 그때도 두 조합의 반경/파수 적분을 분리하고 약한 흡수 계산을
점검한다. 현재는 그 추가 계산이 보류 판정을 바꾸지 않으므로 실행하지 않았다.

## 일곱 조건과 종료한 하위 작업

`closure-map.json`은 PR #166의 원 조건·snapshot 상태와 현재 범위별 근거를
연결한다. 원 파일은 수정하지 않았다.

- PHY-NC: 명시적 number 전달·제조 partial CF/activation·두 밀도의 수치 계약은
  해당 연구 범위에서 근거가 확보됐다. 같은 bridge 구현/시험을 다시 주력으로
  올리지 않는다. 서로 다른 시점 시험을 하나의 새 결합 실행으로 합치지 않는다.
- PHY-SIZE/PHY-OCCURRENCE: 모멘트·광학 소비·고정 mask 대조는 완료다.
  생성 정의와 실제 population/occurrence의 독립 근거는 미충족이다.
- REF-RFMIP/REF-LBL: FAIL 유지.21개 stored strict 셀과 별도 old-solar arm의
  155개는 다른 비교이며 하나의 현재 총계로 합치거나 대체하지 않는다.
- FINAL-IDENTITY: 동결 연구 구성의 소스·실행·재시작 identity는 유지한다.
  과학적으로 승인된 최종 구성을 선택하기 전의 근거를 최종 승인으로 전용하지 않는다.
- FINAL-FORECAST: 37 내부00/11 하루 실행을 최종 공통 조건4/37 예보로 바꾸어
  부르지 않는다. 목적·입력·상태·number·PSD·열원 계약을 먼저 고정해야 한다.

이번 결정으로 공학적 연구 통합이나 A/B/C를 다시 미완료로 되돌리지 않는다.
반대로 문서·재생 성공으로 전체 host 물/에너지나 독립 정확도를 승인하지 않는다.

## 검증과 변경 범위

```sh
python3 -I -S validation/rrtmgp37/first-application-decision/summarize.py --check
```

이 명령은 hash로 묶은 기존 입력/result와 signed 배열에서18개 경계 지표와
3개의59층 가열률 profile을 재생한다. 기존26개 acceptance를 새 과학 실행으로
집계하지 않았으며, 이번에는 acceptance 항목/CI 경로를 추가하지 않았다.
생산 수정이나 전체 과학 실행의 회귀가 필요한 변경도 하지 않았다.

첫 적용의 최종 목적·허용량을 사용자가 지정하면 이 범위와 그 권한을 갱신하고,
적격 독립 기준 dossier와 함께 판정하면 된다. 그 전에 같은 캠페인을 다시
실행해도 현재의 승인 공백을 채우지는 못한다.
