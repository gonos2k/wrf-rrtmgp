# One-use launch contract

`run_serial_audit_once.py --execute` exits before creating a lock or receipt unless `root-authorization.json` exists and binds the exact runner, plan, staged manifest/readback, runtime identity, executable hash, arm order, and time window. The authorization schema is `UDM37_CURRENT_MATTHEW_SERIAL_AUDIT_AUTH_V1`; required fields are `status=AUTHORIZED_ONCE`, the six SHA fields checked by the runner, `issued_utc`, `expires_utc` (at most one hour), `max_forecasts=3`, `model_invocation_budget=3`, `per_arm_timeout_seconds=600`, and `expected_arm_order=[OFF, ON_native4_0, ON_native4_1]`. Root creates this file only after the fresh build/runtime closure and runner have been reviewed.

The runner is one-use: it creates an exclusive lock and durable receipt, runs each serial arm once in order, records each actual return code before log/history parsing, kills the process group on timeout or exception, and stops on the first failure. It clears inherited radiation/audit/capture, OpenMP, preload and boundary-capture variables before setting the explicit environment. It rechecks all staged inputs/links, all tracked build sources, 48 runtime libraries, the four loader coefficient files and expanded table before each launch. There is no retry or duration extension.

All-sky audit CSV call keys must match actual raw capture step/time keys. The 128-seed spread is descriptive, not an IID confidence estimate. Only all-sky metrics are exported. History and final restart outputs require exact data, schema, attributes, masks/fills and finite-value equality across all three arms. The separate radius comparator reports generic/native4 differences; it does not establish observational accuracy or pure engine-only causality.
