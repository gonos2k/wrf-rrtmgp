# Frozen-optics temperature coverage: source review

This read-only review confirms that the generator’s temperature coordinate controls longwave Planck source weighting, not the ice refractive index. `index_at(wn)` reads and interpolates the pinned Warren–Brandt ice-Ih table using wavelength alone (`generate.py:138–145`). The LW integrator separately forms the Planck weight proportional to `nu^3 / expm1(c2*nu/T)` (`generate.py:155–158, 175`). The NetCDF metadata and README state the same distinction (`generate.py:306–314`; `README.md:144–155`). The pinned input hash is `891d0e…370af`.

The candidate 150–330 K axis at 5 K spacing, with the existing 233 K knot retained, is a reasonable way to cover the reported 179.996 K lookup that fell below the old 180 K minimum while providing denser interpolation samples. It is a numerical coverage proposal only. The 233 K knot is preserved for table continuity; the inspected sources do not establish it as a special material calibration point. Keep the lookup’s no-extrapolation behavior and make the supported interval explicit.

This axis does not make the refractive index temperature-dependent or demonstrate that fixed ice-Ih optics are physically valid throughout 150–330 K. In particular, temperatures above melting are not a physical ice-validity claim. The tool remains an experimental homogeneous spherical ice-Ih PSD calculation, without validation of graupel/hail habits, porosity, coatings, mixed phase, or forecast accuracy.

A 5 K grid alone supplies no error bound. Before making an interpolation-quality claim, compare lookup interpolation against direct generator evaluations at independent temperatures between knots, including near 179.996 K and near both endpoints, over representative size slopes and bands. Report the observed errors without treating those numerical checks as physical validation. Existing source and table pins are recorded in `scientific-scope-review.json`; no model, generator, or table was run or changed for this assessment.
