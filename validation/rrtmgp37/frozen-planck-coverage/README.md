# Experimental frozen optics: Planck-temperature coverage

The Matthew UDM27/RRTMGP37 diagnostic queried a positive graupel LW path at the formatted temperature 179.996 K, below the old table’s 180 K minimum. A rebuilt PR65 executable reproduced that rejection under MPI4/OMP2/B32 and printed the direct fatal reason. The original failed runs remain preserved. PR65’s eight remote CI jobs subsequently passed; the local integration build is a copied incremental build, not a fresh pristine build.

`expanded/frozen-ice-psd-moments.nc` adds bounded LW source-weighting coverage from 150 to 330 K at 5 K spacing, retaining the 233 K knot. The original nine size slopes, order128 quadrature, 50 cm⁻¹ maximum spectral spacing, static Warren–Brandt ice-Ih refractive index, material/solar/band data and PSD normalization are unchanged. The table SHA256 is `ebeafb9746164d5414a45eab4061c5c855f0f91e92be77003b3829722514fe6a`. This does not introduce temperature-dependent refractive indices or prove physical ice validity throughout the interval.

All old LW values at 180,233,250,300 K and all SW moment values/source integrals are exactly preserved. Temperature interpolation inside the old interval changes because additional knots were calculated. In 25 sampled in-range midpoint temperatures, the maximum absorption difference from the direct coefficient calculation, normalized by extinction, changes from 2.61054e-4 with the old table to 3.54164e-6 with the expanded table. These are coefficient diagnostics, not W m⁻² errors or forecast-accuracy bounds.

The separate 37-temperature midpoint generation samples 5,328 lambda–temperature–band cells per moment. Its largest absorption/extinction-normalized interpolation difference is 6.56776e-6; the largest across all four moments is 1.01773e-5. At literal179.996 K, the maximum absorption difference normalized by extinction is 1.22877e-8. The logged temperature was formatted, so this nominal calculation does not reconstruct the original cell’s omitted low-order digits. Full diagnostics and pins are stored in `comparison-v2.json`, `interknots/comparison-v1.json.gz`, and `old-vs-expanded-overlap-diagnostic.json.gz`. No acceptance threshold or global error bound was inferred.

The portable CTest `frozen_planck_temperature_coverage` checks old-knot equality, Fortran/Python lookup parity at nine slopes and five temperatures with positive/zero paths, acceptance at150/330 K and179.996 K, rejection just outside150–330 K, and rejection of179.996 K by the old table. It uses the existing implementation-parity tolerances of5e-12 relative and1e-24 absolute. Local GNU compilation and the final test pass. The initial local CTest failure from a missing custom NetCDF runtime search path is recorded separately in `component-validation.json`.

The v1 comparison’s cross-directory kernel-binary hash check failed. Read-only ELF inspection attributed the binary-byte difference to embedded absolute Fortran source paths and corresponding data-address displacements. V2 retains strict source/compiler/flags/input/numerical contracts, validates each available kernel against its own receipt, reports differing binary hashes, and preserves the original failure. The first integration build checker also incorrectly required model execution success strings in a compiler log. Actual compilation returned0, generated the four changed objects and two new executables, and emitted `Executables successfully built`; its separate corrected postflight passes. Both original checker failures remain available; neither correction reran a model or compiler.

This commit adds an optional table and test. It does not replace the old table, change no-extrapolation behavior, change optical material or precipitation/cloud policies, or enable a new runtime mode. An explicitly selected experimental run can use `rrtmgp_udm_frozen_optics=1` and set `rrtmgp_udm_frozen_table` to this expanded table. The homogeneous-sphere ice-Ih graupel/hail approximation, bulk densities, occurrence policy and LW absorption-only limitation remain experimental. There is no completed48-hour Matthew RA37 comparison or observational accuracy claim in this evidence.

Three numerical coefficient generations, one local copied incremental WRF build, and one expected-fatal OMP2 reproduction are recorded here. Coefficient generation and lookup fixtures are distinct from WRF forecast invocations. The old complete RA4 result is reused; no RA4 forecast was repeated for these changes. Compiled libraries/executables and binary WRF outputs are referenced by hashes rather than committed.

Large JSON reports and the raw compiler log are archived losslessly with gzip. `compressed-json-manifest.json` records both compressed and uncompressed hashes; use `gzip -dc FILE.gz` to inspect them. Original uncompressed run files remain in the workspace.
