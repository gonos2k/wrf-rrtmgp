# 정의를 일치시킨 액체 광학 성분 참조의 실제 실행

PR #184 다음 작업으로 **공개 companion의 적분 함수를 실제 실행**했다.
기존 면적-Gamma/Simpson 계산과 별도로 number-Gamma/Gauss–Legendre
적분을 구성하고, 파수 적분도 독립적으로 세분화했다. 선택한 **16개
반경·밴드 조합 모두 사전 수치 screen을 통과**했다. 적격 목록과 각
격자의 raw 소광·산란·흡수·산란 비대칭 모멘트는
[result.json](result.json)의 `coefficient_scope`에 있다.

생산 소스·기본값·계수·미세물리 반경은 바꾸지 않았다. 새 WRF 실행이나
Fortran 컴파일은 없다. 기존 24시간/재시작/A-B-C/PBL 성과는 그대로다.
이번 참조는 **같은 Mie 커널을 공유하는 구형 Gamma8 성분 문제의 수치
참조**다. 원 LUT의 생성 정의, 실제 구름 PSD/발생분율, 전체 스펙트럼의
물리 정확도 또는 일반 예보를 인증하는 결과는 아니다.

## 같은 문제를 계산하도록 맞춘 조건

| 항목 | 실제 적용 |
|---|---|
| PSD | number-Gamma shape 8, 선언한 유효반경; 반경 변수 λr=0…80 |
| 물질 밀도 | 1000 kg/m³; companion의 996 기본값 사용 안 함 |
| 굴절률 | 보존된 Segelstein 25°C 파일; 진공 파장에 대해 n 선형, log(k) 선형 |
| 주변 매질 | n_env=1, m_rel=m/n_env, x=2πr n_env/λ_vac |
| 분광 가중 | LW 298.15 K / SW 5780 K Planck, c₂=1.438776877 cm K |
| 평균 | ext, sca, abs, sca×g의 thin 모멘트 평균; g=평균(sca×g)/평균(sca) |
| 단위 | 질량당 계수 m²/g, 기존 물경로 g/m² |

실행한 외부 소스는
[GRIPS 고정 optics.py](https://github.com/GRIPS-code/cloud_rad_scheme/blob/fe1faba475479c873c88bc98755bcb8c5bb911b1/cloud_rad_scheme/optics.py)와
[고정 spec_util.py](https://github.com/GRIPS-code/cloud_rad_scheme/blob/fe1faba475479c873c88bc98755bcb8c5bb911b1/cloud_rad_scheme/spec_util.py)다.
`gamma_int`와 `convert_lblOD_to_band`는 수정하지 않았다. `mie_coefficients`의
매질 1.0003→1 및 MiePython 3.2.0 API 이름만 바꿨다. 외부 원본과 실행본
해시는 [identity.json](identity.json)에 있다. 외부 전체 소스는 vendoring하지 않았다.
기본 RI/밀도/평균 함수를 그대로 사용한 비교가 아니다.

외부 constructor의 광학 clipping은 입력 검사로 금지했다. 동일 노드의
number-Gamma 적분과 면적-Gamma 표현은 1e-10 상대 screen 이내에서
일치했다. 실제 밀도만 996으로 바꾼 control은 1000/996=1.004016064…를
재현했다. 매질의 상대 굴절률/파장 처리는 high-level Mie API와도
대조했다. MiePython은 **공유한 커널**이며 새 독립 커널로 집계하지 않는다.

## 수치 검증 범위와 실제 결과

주력은 LW6의 6반경, SW6/8의 주간 4반경씩 **14조합**이다.
이전 실패 SW11@22.125196 μm와 SW12@21.5 μm만 추가했다.
실제 반경은 21.5 끝값과 기존 선택점 21.516813…27.660246 μm다.
55 μm나 하한 미달군, 전체 LUT를 검증한 것이 아니다.

각 단계에서 `radius_half`는 파수 격자를 고정하고 반경 노드만 절반으로,
`spectral_half`는 반경 격자를 고정하고 파수 격자만 절반으로 계산했다.
모든 모멘트의 축별 변화 ≤1%×max(|fine|,1e-8), g 변화 ≤0.002가
**실행 전 선언한 수치 screen**이다. 1e-8은 상대 비교의 분모 하한이다.
두 축의 변화 합은 경험적 불확실도 추정으로 별도 보고한다. 축별 통과가
그 합도 1% 이내라는 뜻은 아니다. 이는 사용자 물리 허용오차가 아니다.

| 조합 | 최종 nr/ns | 흡수 반경 축 변화 | 흡수 파수 축 변화 |
|---|---:|---:|---:|
| 주력 14개 | 1024/256 | 최대 약 0.1177% | 최대 약 0.1990% |
| SW11 22.125196 μm | 2048/512 | 0.9870% | 0.2038% |
| SW12 21.5 μm | 4096/1024 | 0.2521% | 0.06354% |

SW12 첫 수준의 반경 축 1.2871% 실패도 보존했다. 사전 허용한 마지막
세분화에서 통과했으며 기준을 바꾸지 않았다. PR #183의 과거 두 실패는
그대로이며, 이번 새 방법의 통과로 과거 결과를 덮어쓰지 않는다.

추가 **16개 교차 계산**은 새 반경 적분에 과거 파수 노드를 사용했다.
같은 signed 모멘트에서 `새−과거 = (새−교차)+(교차−과거)`를 검사한다.
LW6 흡수의 차이는 주로 파수 적분에서 생겼고, SW6/8과 약한 흡수에서는
반경·파수 방법의 기여가 모두 남는다. 밀도나 PSD가 달라서 생긴 차이로
합산하지 않았다. 교차 결과의 `spectral_points_with_RI_knots`는 공통
계산기가 반환한 점 개수 필드이며, 이 교차만은 원 Gauss–Legendre
파수 노드를 사용하고 RI knot를 추가하지 않는다.

## 목표량으로 전파한 실제 18회 기주 실행

기존 진단 실행파일과 동일한 B/C 입력을 재사용했다. 통과한 조합만
fine/radius-half/spectral-half 각각 대입했다. LW6 외 LW 밴드와 미계산
SW 밴드는 기존 독립 계수로 유지했다. 따라서 아래는 **선택 밴드의
부분 대입 결과**이며 전체 스펙트럼 참조가 아니다. B는 끝값 반경,
C는 실제 반경이며 두 군 모두 같은 새 정의를 사용한다.

| C−B 목표량 | 야간 LW | 주간 LW | 주간 SW |
|---|---:|---:|---:|
| 지표 순하향, W/m² | +0.001959691 | +0.007296337 | +0.080672644 |
| native 상단 순하향, W/m² | −0.000060690 | −0.004633956 | +0.082614665 |
| 기주 순수렴량, W/m² | −0.002020381 | −0.011930293 | +0.001942021 |
| 기주량의 축별 변화 절댓값 합, W/m² | 1.52e-10 | 1.23e-8 | **1.60e-5** |
| 59층 가열률 최대 절대차, K/day | 0.04321448 | 0.12274732 | 0.003871433 |

상단은 확장 TOA가 아닌 native 경계60이다. 기주 수렴량은 같은 위치의
`net_top−net_surface`를 직접 계산했다. 가열률은 같은 층의 signed
배열을 보존한다. 지표/상단/기주/59층 각각의 방법 차이와 축별 변화,
위치는 `transport.cases`에 있다. 최대값끼리 빼서 차이를 만들지 않는다.

모든 입력·비선택 계수·기체·rain·clear·mask·uniform 성분·열용량을
보존하고, raw 액체 모멘트 소비와 SW 단 한 번의 delta scaling을
검사했다. 각 native 층의 C·dT/dt와 플럭스 순수렴량도 확인했다.
이는 하루 전체의 acoustic 적용 에너지 재계측이 아니다.

## 이번에 끝내는 판단과 남는 판단

**조건부 수치 참조:** 목록의 16조합에 대해, 선언한 공유 커널·고정
광학 정의 안에서 PSD/밴드 적분의 교차검증용 참조로 사용한다.
51회 축별 평가 +16회 교차 평가 +18회 실제 RTE가 새 계산량이다.
과거 자료 재생은 이 계산량에 더하지 않는다.

수치 불확실도는 축별 세분화의 경험적 추정이며 `certified bound`가
아니다. 두 방법의 차이와 커널 공통 오차도 혼동하지 않는다.
[평가 계약](evaluation-contract.json)은 지표/상단 플럭스, 기주량,
층 가열률별 예산을 나누고 승인되지 않은 물리 허용량을 null로 둔다.
대표성은 이 조건부 수치 명제 밖에 두며 0 오차로 승인하지 않는다.

**과학적 승인:** 원 LUT의 PSD/물질/가중 계보, 실제 PSD와 발생분율,
온도 의존성, 공통 PBL/전체 에너지, RFMIP·LBLRTM FAIL, 최종 4/37·관측
평가는 기존 상태를 유지한다. 생산 계수 대체나 기본값 전환은 하지 않는다.
이제 같은 16조합을 반복하기보다 필요한 적용 대상에 이 참조와 수치
추정을 사용하고, 별도 승인된 물리 예산과 비교할 수 있다.

## 재생 및 새 계산의 구분

```sh
python3 -I -S validation/rrtmgp37/matched-liquid-reference/verify_saved.py
python3 -I -S validation/rrtmgp37/matched-liquid-reference/test_saved.py
```

위 명령은 stdlib 저장 근거 재생이며 새 Mie/RTE 실행이 아니다.
실제 계산은 `run_reference.py`, `check_definitions.py`,
`cross_quadratures.py`, `propagate_reference.py`가 수행했다. 최초 실행은
새 출력 디렉터리만 사용한다. 고정 외부 두 파일은 `/tmp/firstapp_gfdl_*`,
물질자료와 MiePython 3.2.0은 기존 build 의존 경로에 준비하고 SHA를
확인한다. 재현 시 `OUT`을 새 경로로 정해 과거 근거를 덮어쓰지 않는다.
원 실행 로그·실행 중 /proc 관측·RTE의 PID/시각/종료코드·입력·계수·
결과는 `saved/`에 보존했다. `retain.py`는 계산을 실행하지 않는 보존 도구다.
