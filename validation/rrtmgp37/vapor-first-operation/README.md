## 두 최초 연산과 수정 경계

원래 cold 00:00–12:01 관측은 기존 하루 출력과 2,925개 배열이 바이트 동일합니다.
원래 05:59–12:01의 별도 source 관측도 공통 1,575개 배열이 같습니다.

* Source 60 s, native (7,49,20): 포화된 PD antidiffusive flux 제한 뒤 native REAL32
  발산·RK 산술의 분자는 −3.725290298461914e−9입니다. 실제 여섯 outgoing face와
  발산을 재현하면 QV=−3.8907008311720587e−14가 나옵니다. 새 제한은 공유 face
  flux에 기계 정밀도와 피연산자 크기에 비례한 여유를 남깁니다. 갱신된 QV에
  floor를 적용하거나 scalar 질량을 추가하지 않습니다. 이 여유는 물리 허용량이나
  모든 컴파일러·상태에 대한 certified error bound가 아닙니다.
* Source 42,180 s, native (88,98,22): 완화 전 결합 경향은 +6.9779721343365964e−6,
  후에는 −7.1935355663299561e−6입니다. PBL은 양수이고 CU는 이를 바꾸지 않습니다.
  뒤의 지정 경향도 그대로이며 PD source 갱신에서 QV가 −4.492543670409077e−9가 됩니다.
  새 코드는 **유효한 선행 source를 초과해 제거하는 음의 외부 완화 증분만** 제한합니다.
  native old pressure coupling과 실제 전체 source dt를 쓰며, dtbc나 첫 RK predictor dt를
  대신 쓰지 않습니다. 먼저 잘못된 입력·선행 source는 감추지 않습니다.

제한된 실제 외부 교환은 기존 B_relax에 그대로 계상합니다. 강수·number·반경·CF·밀도에
경험적 보정배율을 넣지 않았고, 기존 정책·계수·보호조건도 유지했습니다.

기존 PR189의 675/675 재시작 성공은 역사적 근거로 유지합니다. 위의 새로운 450쌍을
그 캠페인의 재실행으로 이름만 바꾸지 않습니다. 마지막 대조의 이전 구현은 전 영역의
경향을 복사했고, 최종 구현은 자기 tile만 읽어 다른 tile 쓰기와의 겹침을 피합니다.
이 직렬 일치는 MPI/OpenMP의 full-host 지원 인증이 아닙니다.

이 deposit에는 같은 사례의 원인 분리·짧은 대조·구현 대조·최종 평가 WRF 프로세스
12개가 보존돼 있습니다. 독립 기상 사례는 **1개**입니다. 최초 intrinsic 이름 충돌의
실패 컴파일 로그는 개발 기록으로 분리했고, 모델 실행으로 세지 않습니다.
생산기는 보존한 public archive와 실제 source 파일을 사용한 incremental build입니다.
source reference는 `16e4cb4c0d63929987f04e7c946397ac86ca67d9`이며, 그 커밋의 clean
checkout에서 빌드했다는 주장은 아닙니다. 실제 GNU Fortran 13.3.0, O2의 명령·source·
archive·실행파일 해시를 연결합니다. 대형 NetCDF는 실제로 판독했고, 전체 파일 및
배열별 SHA를 저장했습니다. 저장 CI는 원 NetCDF를 다시 읽거나 모델을 실행하지 않습니다.
