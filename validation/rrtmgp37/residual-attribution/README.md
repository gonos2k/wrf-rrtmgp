# Scoped radiation residual evidence

This folder preserves two bounded diagnostics as separate findings. It makes no production change and adds no forecast, REAL, build, or standalone solver calls. Run `python3 -I -S verify_artifacts.py` from this directory to check the packaged files and the reused PR71 log artifacts using only the Python standard library.

## A. Exact-CF-zero precipitation paths

The [audit report](cf0/audit-final-v2.json), [corrected audit notes](cf0/README-v2.md), and [independent log recomputation](cf0/independent-review.json) describe a completed 48-hour RA37 run in experimental frozen-optics mode 1. Positive native rain/snow/other condensate grid paths with exactly zero cloud fraction are tallied from the radiation-call logs. The rain omitted/native path ratios are 28.1813% (LW) and 26.6662% (SW). These are repeated call/tile/rank path ratios; they are not mass or flux errors, unique-domain water budgets, or an occurrence-policy recommendation. The other phases and convective population remain separately reported; LW/SW sums are not combined as unique condensate.

The four raw rank logs are retained in compressed form in the existing [PR69 timestep evidence bundle](../matthew-dt60-timestep-evidence/bundle/dt60-48-hour/ra37/). The bundle manifest records both the compressed artifact hashes and original raw-log hashes. The independent review recomputed 48 aggregate fields from the raw logs and verified their source hashes. The audit’s per-record time/overlap rows live in those logs; the aggregate JSON does not contain those rows. Neither the audit nor this package derives an optical-depth or flux bound from path mass.

## B. RFMIP SW residual and float32 conversion

The [execution receipt](rfmip/execution-receipt.json), [analysis summary](rfmip/summary.json), and [analysis report](rfmip/README.md) bind two standalone SW solver calls: the current coefficient control and a targeted old-solar counterfactual. Both exactly reproduce their respective retained full outputs, pass the full float32 cast check, and have bitwise-equal captured gas optical arrays across solar arms. The [terminal independent review](rfmip/terminal-review.json) is the post-execution readback; its [manifest](rfmip/terminal-review-manifest.json) records its reviewed artifacts. The separately retained [prebuild review](rfmip/prebuild-review-v4.json) is preparatory evidence, not the terminal review. The packaged [instrumented source snapshot](rfmip/rrtmgp_rfmip_sw.F90), [insertion-only patch](rfmip/diagnostic-source.patch), [runner](rfmip/run_diagnostic_once_v5.py), [capture layout](rfmip/capture_format.json), and [failure selector](rfmip/failed_points.csv) make the diagnostic seam reviewable without shipping executable, coefficient NetCDF, or full diagnostic captures.

`rfmip/README.md` is the verbatim analysis note from the scratch run. Its command and relative artifact links describe that original workspace layout; use the links in this package README and `verify_artifacts.py` for the portable checked-in bundle. The copied receipt retains its original external workspace paths as provenance, not as portable paths.

At the 155 preselected old-solar residual cells (116 RSD, 39 RSU), all stored values remain outside the unchanged strict `atol=1e-5, rtol=0` threshold and are one float32 ULP from the published values. All 155 prewrite double values lie outside the target float32 rounding interval; 99 already exceed `1e-5` before conversion, while the remaining 56 are within that absolute threshold before conversion but cross it after storage. Conversion therefore contributes at some cells but does not explain the complete residual. The current-arm figure (154 of 155 selected values over threshold) is a selected-cell result, not a current full-array recount. The retained 116/39 full-array failure count belongs to the old-solar counterfactual.

The old-solar coefficients are a targeted solar-input counterfactual, not authenticated historical coefficients for the RFMIP label `RTE-RRTMGP-181204`; the source revision or generator identity remains unknown. The result does not attribute the strict residual to the WRF port and makes no physical-accuracy claim. There are two standalone SW solver invocations in this diagnostic and zero WRF/REAL forecast invocations. The wider project’s previously reported forecast total is separate and is not a count of this audit.

An earlier report draft misread the driver loop index `b` as a spectral band. The preserved [erratum](rfmip/earlier-report-erratum.md) records the correction: `b` indexes blocks of RFMIP experiment records, and the source is normalized per column using the sum over all g-points and the broadband TSI. The final [v5 diagnostic plan](rfmip/diagnostic-plan-v5.md) uses that interpretation.

## Reuse and limits

The CF0 audit is reused from evidence already present at the base revision; its PR69 compressed logs are linked by relative repository path and hash. The RFMIP execution summary, receipt, source snapshot and small text artifacts are copied here. Large raw captures, result NetCDFs, input and coefficient files, executable and compiler/runtime artifacts remain external; their SHA-256 pins are recorded in the receipt and summary. The verifier checks the package and available PR71 log files but does not assert availability of external workspace files or rerun either analysis.
