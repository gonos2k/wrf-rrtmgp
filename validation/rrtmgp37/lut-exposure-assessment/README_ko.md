# LUT 적용 범위와 제한 구간 물수지 판정

기준 main은 PR181 병합 `36671629c460c013603e50991069a96f2e60ce78`,
전체 tree `ba4d273fd48b79996804cdc7f0f35a621035fe96`이다. 기존 warm-periodic
연구 통합·24시간·조건부 재시작은 완료 범위로 유지한다. 생산 WRF·UDM·RTE
소스, 정책 기본값, 미세물리 반경, 계수, 기존 일곱 종료 조건은 변경하지 않았다.

## 판정

**끝값 제한은 현재 연구 경로의 수치 보호로 유지한다. 그러나 범위 밖 Gamma8의
광학 정확도는 승인하지 않는다.** 외삽 없는 기존 LUT를 사용할
첫 과학 평가 후보 범위는 유효크기 2.5–21.5 μm와 별도의 기존 물리 조건으로
제한한다. 범위 안에서도 PSD·reference·관측 승인은 별도다. 현재
하루 실행의 범위 밖 입자 집단은 유의한 광학 기여가 있으므로 단순 잔여물로
무시하지 않는다. 범위 밖까지 과학적 적용을 확대하려면 같은 PSD·물질상수·
분광 규약의 독립 광학 확장 또는 검증된 fallback이 필요하다. 이번에는 새
정책·경험적 배율·LUT 끝점 변경·응결물 삭제를 생산 코드에 추가하지 않았다.

**선택한 5분 수지 추적은 종료한다.** 실제 source와 적용·질량 평가 경계를
연결해 해당 구간의 잔차를 설명했다. 하루 전체 보존성은 계속 OPEN이며 이
구간의 비율을 하루 보정계수로 사용하지 않는다. `production_accepted=false`와
독립 RFMIP/LBLRTM FAIL을 그대로 둔다.

## 건수 대신 물경로 노출량

기존 289개 history 시각의 같은 시점 건조 층질량×QCLOUD를 사용했다.
AREA2D 및 300초 사다리꼴 적분(처음/끝은 반 가중)으로 물경로 노출량을
분류했으며 CF로 나누지 않았다. 이는 실제 2880회 복사 호출의 clipping
횟수·플럭스 오차가 아니다.

| Gamma8 진단 | 00 | 11 |
|---|---:|---:|
| 하한 미달 건수 | 79 | 40 |
| 상한 초과 건수 | 1145 | 730 |
| 하한 미달 물경로·시간 가중 비율 | 0.0003361% | **0.0002384%** |
| 상한 초과 물경로·시간 가중 비율 | 15.4817% | **8.29215%** |

00은 Gamma8 선택이 꺼져 있으므로 그 열은 가상 진단이며 실제 Gamma8 소비가
아니다. 밴드별 끝값 LUT 소광·흡수·산란·산란 비대칭 모멘트의 가중 진단도
`result.json`에 포함한다. 이는 격자평균 물경로의 광학 노출 지표이며 실제
McICA mask를 통과한 플럭스나 독립 광학 정확도가 아니다.

## 영향이 큰 실제 호출만 재생

11 history에서 상한 초과 물경로가 가장 큰 야간/주간 시각, 하한 미달 물경로가
가장 큰 시각을 고른 뒤 해당 시각의 최대 노출 기주를 선택했다.

| 선택 | source seconds | 물리 기주 i,j | 시작점 |
|---|---:|---|---|
| 상한·야간 | 54300 | 2,1 | 기존 43220초 checkpoint |
| 상한·주간 | 65100 | 1,2 | 기존 64830초 checkpoint |
| 하한 | 9300 | 2,2 | 기존 동일 초기장 |

기존 일반 실행파일로 필요한 구간만 재생했다. 원 24시간의 공통 history 시각에서
각각 37·1·32개 시각의 Time 배열 214개가 바이트 동일하다. 실제 capture의
REL과 RL_USED를 분리하고 끝값 제한을 확인했다. 선택 시각은 history 탐색으로
정했으며 결과를 본 뒤 물리 수용 기준을 새로 만든 검증은 아니다.

같은 public column API를 호출하는 작은 진단 실행기를 기존 libWRF_Core와
RTE 라이브러리에 연결했다. baseline UP/DN/HR·고정밀 출력·mask·cloud optics가
실제 WRF capture와 일치한다. 원 LW 방사율 벡터는 모든 밴드가 동일하므로
API가 지원하는 같은 grey 값으로 전달했고 그 동등성도 검사한다.

대조는 **다른 상태·CF·seed·rain·기체·열용량·경계조건을 유지하고 범위 밖
해당 액체 성분만 제외**한다. Native LWP와 CF0 uniform LWP를 함께 다룬다.
이는 현재 seed/mask에서 성분의 기여도이며, 올바른 범위 밖 광학과 비교한
clipping 오차가 아니다. Seed 간 불확실성이나 관측 신뢰구간을 계산한 결과도 아니다.

| 선택 성분 제외 시 최대 절대차 | LW flux W/m² | LW HR K/day | SW flux W/m² | SW HR K/day |
|---|---:|---:|---:|---:|
| 상한·야간 | 38.44565 | 31.25167 | 야간 미계산 | 야간 미계산 |
| 상한·주간 | 36.02271 | 28.45270 | 8.41211 | 0.225918 |
| 하한 | 0.043457 | 0.023140 | 0.637955 | 0.010514 |

최대값 위치·부호와 prepared 광학 모멘트 변화도 결과에 남긴다. 최대값끼리
더해 합성 효과를 만들지 않는다. 특히 하한 사례는 CF0 uniform 성분이므로
native CLOUD_TAU만 보면 0 차이지만 최종 광학량·플럭스는 변한다.

**표의 31 K/day는 clipping 편향·예보 온도 오차·관측 오차가 아니다.** 광학적으로
기여하는 구름을 제거한 조건부 국소 가열률 차이다. 이 결과는 임의 끝값 확장이나
입자 삭제가 아니라, 범위 밖 정확도 승인 보류의 근거다.

## 실제 source로 분리한 84900–85200초

기존 잔차 시계열에서 큰 음의 증가 구간을 골라 00·11을 같은 물리 시간에서
비교했다. 기존 읽기 전용 source observer를 현재 Registry/modules에 맞춰 다시
컴파일했다. 관측 블록 제거 시 원 solve_em.F와 바이트 동일하며 모델 배열을
수정하는 코드는 없다. 각 재생의 공통 history 68개 시각×214개 배열이 원래
실행과 동일하다. 기록은 선택한 30개 accepted step에만 한정한다.

| kg/m² | 00 | 11 |
|---|---:|---:|
| 관측 잔차 증가 | −2.44716864e−4 | −2.79976270e−4 |
| PBL dry-mass 반환−QFX | −2.37002179e−4 | −2.72508054e−4 |
| 재구성 후 미설명 나머지 | +6.10e−14 | +6.97e−16 |

실제 PBL→PD source coupling, PD 적용, RK 산술, 미세물리, QFX와 ACLHF의
정밀도 차이, 내부 순수송, 질량 평가 경계를 별도 기록했다. 질량 평가 경계는
`M1*q1−M0*q0=(M1−M0)*q0+M1*(q1−q0)`로 분리했으며, 여기서는 q 부분이
정확히 0이고 질량 평가 차이만 남았다. 최대 상대 carrier 차이는 약 3.18e−7/
2.53e−7이다. History의 REAL64 질량 평가와 실제 기록의 REAL32 평가도
끝점에서 따로 연결한다. 재구성 허용범위는 기록된 inventory의 REAL64 합산
오차 상계로 계산하며 물리 허용오차를 결과에 맞춰 완화한 것이 아니다.

이는 같은 질량 규약에서 지표 source가 정확히 보존된다는 승인도, 모델이 물을
덜 잃도록 수정했다는 결과도 아니다. 두 구성의 상태·지표 source가 이미 다르므로
그 차이를 복사 정책의 직접 물 source 오류로 해석할 수 없다. 하루 전체 수지·
장기 실제 적용 에너지·전체 열역학·관측 정확도는 계속 미승인이다.

## 실행과 재현

새 WRF 구간 실행 5회(광학 capture 3, 물수지 2), public-column 프로세스 15회,
Fortran 컴파일 3회(진단 caller 1, 읽기 전용 observer 2)를 수행했다. Observer
첫 빌드는 실행하지 않았고 로그 구간만 좁힌 두 번째 빌드를 사용했다. 새 전체
WRF 빌드·24시간 반복·독립 Mie/LBLRTM 캠페인은 없다. 이 수를 기상 사례 수로
해석하지 않는다. stderr/RC, build/link, source·실행파일·library identity,
실제 recipe, capture·대조·source 원문을 saved에 보존했다.

기존 PR181 history와 공식 LUT export는 `prior-evidence.json`의 경로·해시로
재사용한다. 과거 해시를 덮어쓰지 않는다. 저장 근거 검사에는 모델 실행이 없다.

```sh
python3 -I -S validation/rrtmgp37/lut-exposure-assessment/verify_saved.py
python3 -I -S validation/rrtmgp37/lut-exposure-assessment/test_saved.py
```
