# Column-batching diagnostic evidence

This compact scratch package records bounded diagnostics for the UDM37 column-batching issue. It does not change source, alter tolerances, or claim production acceptance. The original unshimmed numerical mismatch remains an unresolved behavior.

## Findings and limits

- **Unshimmed first-step WRF diagnostic:** four actual runs compared B=1 and B=32 at OMP=1 and OMP=2. Strict B1/B32 differences remain; within each batch size, OMP=1 and OMP=2 histories are bitwise identical. The v3 four-run runner itself ended `FAILED_POSTFLIGHT` because prior-v4 bookkeeping compared tuple/list representations differently across 12 pairs; a pinned posthoc attestation revalidated output quality. An earlier v1 single-run observation had a separate wrong-history-variable issue.
- **v9 WRF matrix:** strict comparison failed although all seven new model runs returned successfully. Old37-to-B1 and RA4 preservation passed; B=32/64/128 payloads match each other, while B=1 comparisons differ. At 00:10, the first differing output fluxes were small, but coupled QNCCN/QNCLOUD/QNRAIN changes were large and unexplained. No tolerance change or causal attribution was made.
- **Process-wide vector-math intervention:** a fresh shimmed B32 run and previously validated shimmed B1 are bitwise identical across three histories and the checkpoint, including all variables and metadata. Shimmed B1 is also bitwise identical to its unshimmed B1 counterpart, while shimmed B32 differs from unshimmed B32. The four computational ranks recorded positive vector-math counters. This is strong evidence that a process-wide vector-math intervention changes the batch-32 result in a way consistent with the observed mechanism. It does not identify an RRTMGP-only call site, establish production correctness, or erase the original unshimmed mismatch. The interposition applies process-wide.
- **Offline frozen SW tests:** one captured SW profile repeated at ncol=1/32/64/128 is bitwise invariant for 18 returned groups. A separate 32/64-column synthetic perturbation test is also bitwise invariant. These do not test WRF host packing or actual heterogeneous columns.
- **Offline frozen LW test:** one captured LW profile repeated at ncol=1/32/64/128 is bitwise invariant for seven groups (six flux/heating outputs plus MCICA mask). The capture itself had no mask, so mask evidence is replay shape-invariance only. Scalar replay matches captured REAL32 flux/heating and isolated native-theta conversion; wrapper scatter and radiation-driver accumulation are untested. A separate synthetic 32/64-column LW replay is exact, but does not represent host-packed heterogeneous columns.
- **Scalar/vector math probe:** compiled objects contain scalar/vector libm paths; isolated probes differ by up to 3 ULP. These static and isolated results do not by themselves identify the WRF cause.

The investigation inventory records 39 actual model invocations (16 reference, 23 candidate) and zero benchmark models. The evidence here is limited to the described short diagnostics and offline replays. No NetCDF histories, executables, coefficients, or raw sessions are included; external source receipts and hashes are listed in `source_references.json`.
