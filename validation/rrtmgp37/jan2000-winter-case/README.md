# January 2000 winter case: RA4 baseline and open RA37 failure

The paired winter run does **not** validate a full RA37 forecast. UDM microphysics (MP27) with RA4 completed 24 hours; RA37/frozen-optics mode1 stopped at 14:50 UTC on a material negative QI input. This evidence preserves that failure, the preceding setup failure, the common inputs, and an official WRF RA4 control. It changes no source, physics, thresholds, or runtime data.

| Run | Observed outcome | Retained scope |
| --- | --- | --- |
| Paired v1 | RA4 failed because the working directory lacked CAMtr setup; RA37 was not executed | Original plan, runner, receipt and four rank logs |
| Paired v2 RA4 | Four ranks completed Jan24 12Z–Jan25 12Z | 25 hourly history Times; 221 numeric history variables and 663 numeric variables in each of two restarts checked finite/unmasked/nonfill |
| Paired v2 RA37 | LW rejected QI at Jan24 14:50Z | Three saved history Times (12, 13, 14Z), rank logs and hourly species analysis; failure remains OPEN |
| Official upstream RA4 | Model completed; original harness guard failed on randomized `ldd` addresses | Preserved guard failure plus offline normalized dependency check and exact history comparison; no rerun |

The archive is the [NCAR January 2000 WPS test dataset](https://www2.mmm.ucar.edu/wrf/users/download/test_data.html), downloaded from the official `wps_30km.tar.gz` URL recorded in [download-receipt.json](archive/download-receipt.json). The index describes 36 hours at six-hour intervals; the actual archive contains nine Times at three-hour intervals covering **24 hours**, Jan24 12Z–Jan25 12Z. The run uses only that actual coverage, one 30 km domain (73×60×32 mass cells), a 60 s timestep, MPI4/OMP1, MP27 and `use_mp_re=1`.

The two v2 arms share identical initialized input and boundary files, dry-mass conventions, runtime assets and executable. Namelists agree after normalizing case paths and only RA_LW, RA_SW and frozen mode. RA4 uses mode0; RA37 uses mode1 with frozen table SHA `8cb00850c3f885f5ec0306563c1ec0a55b512478a7395d626c1c99cebf280583`. [The v2 plan](v2/pair-plan.json), [runtime asset manifest](v2/runtime-link-manifest.json), [preflight](v2/preflight-verification.json) and [execution receipt](v2/run-receipt.json) retain exact pins. Plans/preflights retain their historical pre-execution status; the execution receipt determines the outcome.

The actual compiled winter source is commit `e7c97ed661403b3922fcf752300c052611ef89cd`, with source tree, configure and binary hashes recorded in the plan. [Source comparison](source/source-equivalence.json) verifies that its tracked production WRF content matches this evidence branch's PR26 base `792f36b6bbc442f0db37b5cb9fdf19dd33600082`. Four differences are confined to SR regression tests and test CMake wiring. Generated build products are outside that tracked-source comparison. This evidence applies to the recorded runtime stack; it is not a test of later workspace, selector or diagnostics stacks.

RA37 rejected `QI=-5.623554244493789e-8 kg/kg dry air` at global Fortran `(i,j,k)=(17,58,7)` on rank2. The permitted negative-only correction ceiling was `9.999999960041972e-13`, approximately 56,235 times smaller in magnitude. The guard correctly stopped; no threshold was relaxed. [The original analysis](analysis-original/causality-analysis.json) retains the fatal log and saved-state statistics. The last hourly state at 14:00 is **not** the 14:50 failing radiation input. Its reconstructed dry mass/path is a snapshot estimate, not an actual fatal-call water path. RA4's finite outputs and small negative hydrometeor values do not establish that RA37's material negative is harmless.

[The actual-source recheck](source/actual-winter-call-order-recheck.json) locates radiation in `dyn_em/module_first_rk_step_part1.F`, before the later current-timestep tendency and microphysics calls in `solve_em.F`. UDM subsequently copies `max(q,0)` into local microphysics arrays. This order does not identify which preceding process created the failing prognostic QI. The original analysis accidentally cites four source hashes from a different runtime tree and names a `phys/` path for `module_first_rk_step_part1.F`; it is preserved unchanged, and the recheck supplies the correct winter source pins/path/line references. Attribution remains OPEN.

The independent upstream WRF v4.8.0 RA4 control uses commit `06d4240ae989cc3e50af412bb472df3d9048783c`, its own binary/configure, the same input/boundary assets and MPI4/OMP1. The pristine namelist removes port-specific settings; the exact change is retained in [namelist-removal.diff](official-ra4/namelist-removal.diff). Its original runner failure is bookkeeping: all four model ranks succeeded, but raw `ldd` process addresses differed. [Offline comparison](official-ra4/posthoc-comparison.json) verifies unchanged 52 resolved dependency paths/hashes, all 222 history variables, dimensions, variable/global attributes and 25 Times, with zero raw-byte differences and no asymmetric variables. The whole 192,549,864-byte history is identical to patched RA4 (SHA `edf0cfbf4efeecbbf69e979c8f4fc21a19a436f4329a3e11330a2c569ea0bcc4`), also independently [rehashed by root](official-ra4/root-whole-file-identity.json). Both official restarts have 663 finite numeric variables, but their whole-file hashes differ from the patched restarts: this package makes no restart byte-equivalence claim. This is an RA4 preservation control for one case/layout, not a RA37 physical oracle or forecast-skill result.

[The observational appendix](observations/README.md) compares accumulated-energy hourly means with QC0 NOAA SURFRAD records at three sites. RA4 has 24 intervals; RA37 only two before failure. It retains nighttime negative measurements and makes no daily RA37 or winner claim.

It checks every retained file hash, original-copy provenance, input equality, failure scopes, finite-data receipts, source errata, normalized dependency checks and history identity. It also recomputes observation score arithmetic from retained interval CSVs; it launches no model and does not revalidate omitted external files. Byte-exact original namelist/configure snapshots and the preserved mechanical diffs retain their original trailing whitespace. Default `git diff --check` reports those nine original paths plus CRLF line endings in the HTTP header and two observation CSV snapshots (twelve paths in total); authored documentation/verifier checks are reported separately without normalizing factual pins. The RA37 winter failure remains unresolved; this package makes no full winter RA37 validation, cross-physics causal attribution, or general forecast claim.
