# UDM option-37 LW trace-gas coverage audit

This is a source/data inventory only. I did not change production or test files, and I did not measure an isolated radiative residual for the four omitted species.

The checked-in RRTMGP coefficient metadata is pinned in `WRF/external/rte_rrtmgp/DATA.json` to `earth-system-radiation/rrtmgp-data` commit `ea788bb39876948fa8d2c235665ccff19b4686b5`. The local LW and SW NetCDF files match the manifest SHA-256 values. Both contain 19 `gas_names`, including `ccl4`, `cfc11`, `cfc12`, and `cfc22`. LW lower/upper minor-absorber intervals place CCl4 in band 5, CFC11 in band 6, CFC12 in bands 6 and 8, and CFC22 in bands 5 and 8. These are minor absorbers, not key species. The SW coefficient file has no lower/upper minor intervals or key-species slots for these four, although their names appear in its shared metadata.

The current RRTMGP adapter declares and supplies only `h2o`, `co2`, `o3`, `n2o`, `ch4`, and `o2` (`WRF/phys/module_ra_rrtmgp.F:44,217-236,413,554`). The legacy LW call in `module_ra_rrtmg_lw.F` still passes `cfc11vmr`, `cfc12vmr`, `cfc22vmr`, and `ccl4vmr` (`13059-13062`), and the WRF wrapper fills those arrays per layer (`12348-12358`). On the RRTMGP path, the LW call at `13046-13055` passes only the six common gases. The pinned RRTMGP loader filters minor intervals against `available_gases` (`mo_gas_optics_rrtmgp.F90:1969-2054`), so absent CFC/CCl4 channels are dropped when coefficients are initialized, rather than retained with runtime zero VMR.

For `GHG_INPUT=1`, WRF’s existing `read_CAMgases` routine supplies time-varying CFC11 and CFC12 from its CAM trace-gas input. CFC22 and CCl4 remain static constants in this wrapper. For `GHG_INPUT=0`, the source-defined fallbacks are 0.251 ppb CFC11, 0.538 ppb CFC12, 0.169 ppb CFC22, and 0.093 ppb CCl4. The JSON records exact source lines and file hashes. These defaults must not be substituted for a dynamic run’s actual values.

The omission’s LW-only radiative flux/heating effect remains unquantified. A total RRTMG4–RRTMGP37 difference is not a CFC residual: it also contains spectral-grid, solver, cloud-optics and other differences. To isolate the effect, compare two scratch RRTMGP runs using one captured column and identical thermodynamic state, six common VMRs, surfaces, clouds and sampling: current six-gas behavior versus explicit per-layer CFC11/12/22/CCl4 VMRs from that run. Compare gas optical depth by g-point, surface and TOA up/down LW fluxes, and layer heating. Begin clear-sky; optionally repeat with the same cloud state and fixed sampling mask. Only then report a separate RRTMG4 comparison with the same VMRs as a composite engine difference.
