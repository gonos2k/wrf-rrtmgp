# Held-call occurrence and ice-size inventory

This inventory reads retained actual serial captures. It invokes no model, build, or reference solver. `inventory.py` verifies each capture against its original hash inventory, parses the exact input/raw/result records, and records finite values, layer eligibility, masks and source compatibility. The output is an observational inventory, not a new strict optical replay PASS.

The existing reference is `build/udm-cu-focused-v2/reference_column`, SHA256 `67261df7bda1fa7472216b87fdc79b1c93c72fdeae5ff812e2e3e7c372d5d21a`. Its recorded reference source exactly matches PR60 source `9ab10866c9b398c059310c74b3824b7273c42f180dd48a1643229d76714464cd`. The executable generation reconciliation and newer 20-call receipt are retained as external pins. This establishes the old executable generation; it does not establish current production vendor linkage. Current backend and scalar-math code differ from the capture source. Reference source equality, unchanged cloud/gas files and table, and a fresh strict baseline can justify a held-state reference experiment, not a current PR60 forecast claim.

## Minimal proposed experiment, not executed here

First reproduce the three selected LW/SW baseline pairs with the existing pinned reference, unmodified capture inputs and strict legacy/new-version comparisons. Validate all mandatory sections, mask, raw extinction mapping, coefficients and frozen table. Preserve any failure and stop before sensitivity work.

Then a separately authorized native experiment can remove the optical contribution of only the pure-ice clipped layers above. Report flux/heating changes as **finite-layer contribution**, not clipping error or an out-of-LUT reference. Hold gases, atmosphere, surface, solar spectrum, CF, seed/mask and precipitation/frozen components fixed. LW may remove only selected IWP at fixed CF. V9/V11 cannot ordinarily mutate paths: raw optical checks intentionally reject that. For SW, construct the native/CU optical moments after component removal, apply the existing single cloud delta scaling and existing precipitation order, and use the prepared-optics override while leaving capture/raw inputs unchanged.

`reference_column.f90:891–912` applies the override after cloud/precip preparation and before sampling; it then checks recorded mask and original raw cloud/precip extinction. `:1081–1172` reads `WRF_SW_OPTICS_OVERRIDE_V1`, exact dimensions, pinned band bounds and finite TAU/SSA/ASYM. The known legacy band-split mapping is not acceptable for this experiment; use exact pinned RRTMGP bands. The override does not change the recorded raw cloud extinction used by the separate direct beam. Consequently a prepared-cloud-only SW experiment has a **hybrid direct-beam limitation**: diagnose diffuse/up/heating contribution separately and do not claim fully consistent direct-beam extinction removal. A consistent direct-beam component-removal experiment needs a separately reviewed diagnostic extension; no such change is included here.

CF0 paths remain outside the shared cloud mask by contract. Changing CF or overriding pre-mask cloud optics does not isolate precipitation. Independent CF0 precipitation requires an explicit, separately reviewed occurrence/mask and post-sampling addition; neither its true occurrence nor out-of-LUT ice optics is present in these data. No arbitrary extrapolation, uniform occurrence assumption or physical accuracy closure is proposed.

The current-size library uses ice diameter10–180µm, not effective radius10–180µm. Clipping requested diameter to180 establishes a bounded query and an exposure metric; it does not establish the error of that query. Hourly MPI history is not an exact radiation-call replay. All scientific policies remain open.

`preparation-failure-v1.json` preserves a parser-key staging mistake corrected to the actual raw labels. No scientific file was changed. External receipts/raw datasets remain at their pinned original paths; the inventory is not a portable substitute for those files.
