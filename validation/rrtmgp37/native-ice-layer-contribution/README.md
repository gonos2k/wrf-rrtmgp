# Held-state native ice-layer contribution

This evidence records six unchanged reference baselines and six additional offline reference calls for two historical native ice anchors. It adds no WRF model or build. Both SW prepared-optics controls reproduce all46 baseline arrays bitwise; the four layer-removal variants preserve their original masks, gas, precipitation, frozen and clear-sky arrays.

The [inventory summary](inventory/summary.json) gives exact eligibility and source compatibility. The [independent baseline review](baseline/independent-review.json) recomputes the retained baseline comparisons without invoking the solver. The [sensitivity receipt](sensitivity/execution.json), [readback](sensitivity/readback.json), [independent sensitivity review](sensitivity/independent-review.md) and [detailed scope report](sensitivity/README.md) preserve selected-layer counts and vertical flux/heating differences. Original evidence files and helpers were copied byte-for-byte; [index.json](index.json) records their original paths and hashes.

These fixed-seed gpoint fractions are not domain fractions or time integrals. Mixed high-anchor k14–16 remain present.

SW replaces selected prepared layers with original delta-scaled precipitation optics; LW changes only selected IWP at fixed CF/seed. Here `PREPARED_*` means prepared solver cloud-plus-precipitation optics after precipitation increment, before mask sampling and separate frozen addition. The negative controls reject an actual mixed layer and an incorrect cloud-optics replacement without additional solver calls. **SW pre-delta raw extinction/direct stays baseline and is EXCLUDED_FROM_COUNTERFACTUAL.** Solver DIRECT is reported separately; the experiment is not a physically consistent modification of every SW diagnostic.

This measures the finite-layer contribution of ice associated with clipped lookup sizes. It does not measure clipping error, out-of-LUT optics, physical accuracy, domain means, CF0 precipitation occurrence truth, independent CU ice effects or operational approval. The 65 retained winter native/CU triples have no clipped ice-only population layer: their clipped CU layers also contain liquid. Actual CF0 rain/snow omitted mass is available in the inventory, but a true independent precipitation occurrence/mask is not.

The existing reference executable and reference source are pinned, and its source matches current PR60 reference source. Current production backend/scalar-math code differs from the historical capture source. Replaying these columns does not prove current production vendor linkage or a current forecast trajectory. The winter daylight capture source ran six hours; a byte-identical reused LW record from a separate run does not establish common trajectory. Active-CU fresh validation is pending separately and is not represented by these results.
