# MPI collective loader-failure evidence

This evidence bundle records four bounded two-rank startup failures using the approved dm+sm executable (WRF source commit `e7c97ed661403b3922fcf752300c052611ef89cd`, SHA-256 in `summary.json`) and the 12:00 restart used by the PR28 runtime checks. The PR worktree itself is based on `fdafa534d5641fa2251ad5b02d294d57167b81fb`. The six production loader/callback files listed in `summary.json` are byte-identical between that PR base and the executable source commit `e7c97ed661403b3922fcf752300c052611ef89cd` (the PR26-equivalent loader implementation). No production code is changed in this evidence branch.

The cases are a missing private SW cloud coefficient, a private LW gas coefficient truncated to 128 bytes, a missing private frozen LUT, and a private frozen LUT with a malformed NetCDF header. All use RA37 LW/SW, frozen mode 1, MPICH two-rank fork launch, OMP=1, and a 60-second cap. They exit nonzero in about 5–6 seconds. Rank 0 logs the loader error and MPI_Abort; rank 1 starts and is terminated as part of the MPI communicator. Both rank logs are present. The fresh receipts record the live case-scoped process list before cleanup: it was empty, no cleanup action was taken, and no rank remained. This is evidence for communicator termination on these four loader failures; it does not claim the failing loader ran independently on every rank.

The checked source path installs a fatal callback that dispatches through WRF `wrf_error_fatal3`. Shared coefficient, frozen-table, restart, input, and executable hashes are unchanged before and after. Only hashes and byte counts for private coefficient copies are included; the large coefficient files themselves are omitted.

The frozen-table reader calculates and exposes a SHA-256 and re-hashes after reading to catch a file changing during load. It has no trusted expected digest input or embedded checksum comparison. Thus the malformed-header probe demonstrates NetCDF format rejection, not authentication of a valid but modified table.

The exact scratch commands, case-specific namelists, compact receipts, and rank logs are retained here. Runner source paths reflect the local test workspace and require its pinned executable, restart, and data assets to replay. This artifact does not claim forecast completion, broad startup-error coverage, or MPI numerical accuracy.
