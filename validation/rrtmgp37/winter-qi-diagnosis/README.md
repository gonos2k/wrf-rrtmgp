# Winter QI radiation-input diagnosis

This package preserves two observational replays and source-order audits for the winter UDM27/RRTMGP37 case. It contains no production-source changes. The second replay measures the immediate CU augmentation at the radiation interface; it does not identify the earlier KF arithmetic that produced the diagnosed CU value.

## What the first replay establishes

At radiation step 171 (elapsed 10,200 s), the LW wrapper capture stage `RAD_PRE_BUILDER` recorded `QI=-5.623554244493789e-8 kg/kg` at i=17, j=58, layer 7; the error code was `RRTMGP_INPUT_UDM_QI_NEGATIVE`. `RAD_PRE_BUILDER` is a capture-stage name, not the fatal error label. The capture records wrapper input, not prognostic storage. The retained stage capture brackets that with native `QI_native_UDM_POST/BC0 = 0` at the end of the preceding step. The correct comparison is `POST_SPEC_BDY(n)` to `RAD_PRE_BUILDER(n+1)`, because the WRF driver invokes radiation before the next UDM microphysics update.

The static audit found a temporary radiation-preprocessing path that augments QI with a convective contribution, then restores the saved QI after the radiation calls. A second component hook measured `QI_native_UDM_POST/BC0 = 0`, pre-CU QI = 0, `QI_CU=-2.811777051192621e-7 kg/kg`, and positive shallow cloud fraction `0.20000000298023224` at the same cell and time. Their product is `-5.623554244493789e-8 kg/kg`, exactly the captured post-CU and fatal builder value in float32. The boundary-layer cloud-ice branch was inactive (`ICLOUD_BL=0`). A separate positive-CU-radius readback at k=8 found native QI=0, positive CU-augmented wrapper QI, and the wrapper radius at the native zero-ice UDM minimum (~5.01 µm); this proves radius association only, not a flux error or a preferred replacement model. The k=7 component proof establishes the immediate radiation-input cause as the CU augmentation; it does not identify the earlier internal KF calculation that produced negative `QI_CU`, nor show negative prognostic UDM/dynamics QI. Static ordering checks also rule out the final specified-boundary update as the direct writer at this cell; they do not identify an earlier physical tendency.

The first replay's original history postprocessor failed immediately with `NetCDF: HDF error`. That failure is retained as-is. A separate posthoc readback subsequently opened the same file in two reader environments and confirmed whole-file SHA256 `e3fa7be56062c640e52f66c73aaa0bd798d56f0809c1d4501e3b4a0c9c227e4c`, 225 variables (224 numeric), three finite time records, and exact byte identity. The cause of the original transient reader failure is unknown; the model was not rerun and the file was not repaired.

## Remaining attribution limit

The CU contribution to the radiation input is measured, but the internal KF process that generated the negative diagnosed `QI_CU` is not traced to a specific equation or tendency. The evidence does not establish a dynamics/UDM sign failure, nor does it validate a sanitizer or other operational correction. The static policy audit discusses possible handling choices as proposals only.
