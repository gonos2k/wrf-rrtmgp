# Winter QI one-point observational hook (scratch only)

The observer lives only in `source/WRF` copied from staged commit `e7c97ed661403b3922fcf752300c052611ef89cd`. It is opt-in through `WRF_UDM_WINTER_CAPTURE_DIR`, cached once under an OpenMP critical region, and only emits for global `(i,j)=(17,58)`, levels 6–8, with elapsed model time 10,020–10,260 seconds (14:47–14:51) and a broad diagnostic timestep guard 167–172; elapsed seconds is authoritative because solve_em increments itimestep before first_rk_step_part1/radiation. It only reads state. The output directory must already exist. Each MPI rank appends to its own `rankNNNN.csv`; the row layout is stage, rank/domain/step/i/j/k, seconds, 16 observed reals (QC,QI,QR,QS,QG,QH, three radii, radiation CF, UDM CF, QNN/QNC/QNR, native dry mass, stage-specific temperature), then memory and active bounds. A `temp_kind` text column labels the final observed real: `THETA_K` for UDM, `T_2_K` in solve_em checkpoints, and `T3D_K` at the LW radiation-builder input; all values are in kelvin, but these model arrays are not interchangeable thermodynamic definitions. `-999` denotes a field unavailable at that capture point.

Capture stages are `PRE_MICROPHYSICS`; `UDM_PRE`/`UDM_POST`; `POST_PHYSICAL_BC`; `POST_SPEC_BDY`; and `RAD_PRE_BUILDER`. The latter records builder inputs and native layer mass immediately before `rrtmgp_build_udm_inputs`, before the expected negative-QI fatal. UDM stages capture all six hydro q and number fields at levels 6–8. The `PRE_MICROPHYSICS` capture executes outside the OMP tile loop, so its ownership gate and reported i/j bounds use the rank-owned patch (`ips:ipe`, `jps:jpe`); the other solve-stage hooks use their active tile bounds. Solve stages capture the middle level (k=7) around microphysics and boundary updates.

## Static source bounds

The frozen Jan case has `e_sn=61`, `spec_bdy_width=5`, and `spec_zone=1` (Registry default). In `solve_em.F` the UDM call uses `sz=grid%spec_zone`; for specified boundaries it sets `jts=max(tile_jts,jds+sz)` and `jte=min(tile_jte,jde-1-sz)`. With `jds=1,jde=61`, active global rows are 2 through 59. `module_mp_udm.F` processes `jts:jte`, so j=58 is within UDM's physical update interval when owned by a tile. The later final specified-boundary operation in `module_bc.F` uses `spec_zone=1` and selects the outer row j=60; j=58 is not overwritten by that final row operation, despite being inside the wider five-row specified relaxation zone. Capture remains necessary to establish actual per-rank/tile ownership and values.

`solve_em.F` increments `itimestep` at line 384, then calls `first_rk_step_part1` at line 815. Radiation is inside this first-RK routine and occurs before this step's scalar update and time-split UDM call. The current timestep then reaches UDM, `set_physical_bc3d`, `spec_bdy_final`, and `after_all_rk_steps`; the next timestep runs prep and radiation before another UDM call. Therefore compare `POST_SPEC_BDY(n)` with `RAD_PRE_BUILDER(n+1)`, rather than rows carrying the same step label. The original fatal is at elapsed 10,200 seconds (14:50); because WRF increments the step counter before radiation, the hook uses a broad step guard 167–172 and makes elapsed seconds 10,020–10,260 the authoritative window. The exact failing radiation input must be present in the capture row on the same MPI rank as the fatal log before the replay is considered diagnostic success. This brackets state transitions only; it does not identify the physical producer of the negative value.

## Bounded replay proposal (not executed)

The runner `run_capture_replay.py` stages only into a new path and defaults to preflight; `--execute` is separate. Preflight pins the helper executable, all five instrumented source/config files, all 94 top-level runtime links, table, input, boundary, namelist, and the original fatal log/history. A future authorized run uses the original full-duration namelist (the fatal should stop it after 170 simulated minutes), 4 MPICH ranks, OMP=1, local NetCDF/root/MPICH shared libraries, and a 600-second process-group timeout. It then requires an elapsed-10,200-second `RAD_PRE_BUILDER` k=7 row with the original QI value on the same rank as the fatal and verifies all variable arrays at history times 12:00, 13:00, and 14:00 bytewise against the original partial output. Variable schema, dimensions, masks, and finite numeric values are checked; metadata differences are reported separately. If raw history records differ, the capture is a divergent replay and cannot establish the original fatal trajectory. No model execution has been performed by this hook task; the fresh `replay-v7` directory is preflighted and any later source/helper changes require a new directory and new pins.
